## Как работаем дальше (коротко)

1. Ты запускаешь приложение и присылаешь скриншот или текст ошибки.
2. Я исправляю пачкой, коммичу, пушу.
3. Ты делаешь `git pull origin main` и запускаешь снова.

## Как запустить (PowerShell, из папки репозитория)

```powershell
git pull origin main
git log -1 --oneline
npm install
npm run dev
```

`git log -1` должен показать коммит новее `28bf87f`. Если порт 1420 занят старым сервером, закрой старое окно приложения и терминал, затем повтори.
