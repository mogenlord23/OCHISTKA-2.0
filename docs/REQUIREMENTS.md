# Требования владельца (живой документ, не удалять)

Обновлять при каждом новом замечании. Каждый пункт — проверяемый критерий.

## Оболочка и окно

- Панель справа: активный пункт — квадратный скруглённый блок (не прямоугольник), иконки крупные и понятные.
- Верхняя линия обводки кнопок окна (свернуть/развернуть/закрыть) и верхняя линия панели — на одной горизонтали. Все элементы выровнены по сетке 8 px.
- Развёрнутое на весь экран окно: без скруглений и внутренних отступов. Обычное окно: скругление.
- Панель всегда полностью видна при любом размере окна, без прокрутки.
- Скроллбары не показываются нигде.
- Все разделы одинаковые по сетке и отступам: одинаковые поля, центрирование, ширина контента.
- Анимация сворачивания блока «Звук / RU / ENG» в маленькую стрелку и разворачивания по наведению.
- Версию приложения не показывать.
- Порядок разделов: VPN, Вирусы, Процессы, Программы, Диски, Компьютер, Оформление. VPN открывается первым.

## Фон и постер

- Фон приложения — паттерн из старого репозитория (`pop-pattern.png`), тусклее, чтобы не бросался в глаза.
- На странице VPN — постер из старой версии (`pop-art.png`, фигура Че Гевары). Кадрирование: лицо не обрезано при растягивании, картинка не меняется по-разному при изменении размера окна.
- Клик по постеру — пасхалка: звук `heehee.wav` и анимация нажатия.

## Звук

- Кнопка «ЗВУК» работает (вкл/выкл), состояние сохраняется. Пасхалка и остальные звуки подчиняются ей.

## Драйверы/настройки/буст

- Отдельного переключателя ОС в «Настройках» и «Бусте» нет. Версии для разных ОС будут разными сборками. Сейчас только Windows.

## VPN

- Вкладки: VPN, Дополнительно, Сеть, Соединения.
- «Дополнительно»: карточки Zapret и Xbox DNS, как на скриншоте владельца (owner-2/vpn-extra.png). GoodbyeDPI скрыт.
- Соединения: без лишних галочек; один элемент управления максимум.

## Процессы и программы

- Иконки процессов и программ — настоящие иконки приложений, квадратные, скруглённые, чёткие.
- Сортировка по клику на заголовок колонки: первый клик — от большего к меньшему (память, CPU, размер), второй — наоборот. Со стрелкой.
- Единицы человеческие: МБ, ГБ, %. Без сырых битов.
- «Удалить» работает: штатный деинсталлятор после подтверждения.
- Правая кнопка мыши по строке — меню (размер папки, путь, удалить).
- Автозагрузка: выбрать запись и отключить/включить, с откатом.
- Выделение строки — аккуратная обводка в цвете раздела, без «полосы».

## Компьютер

- Сверху строка «CPU / GPU / RAM» с процентами (мелко, информативно).
- Плитки: CPU (чип, лаймовый), GPU (видеокарта с кулерами, розовый), RAM (две планки, синий), материнская плата (жёлтая), SSD/HDD (диск, розовый), система (монитор). Иконки крупные и однозначные.
- Плитка показывает название: процессор, видеокарту, модель диска (например «KINGSTON SHFS37A120G»), сокращённо, без длинных серийных номеров.
- График открывается только по клику на плитку (CPU, GPU, RAM, диски). Анимация открытия плавная.
- Видеокарта: карточка с графиком 90 секунд, драйвер, разрешение.

## Оформление

- Обои: выбранная обводка без галочки, без подписей (hex, «сплошной цвет», «применено»). Выбор ставит обои на РАБОЧИЙ СТОЛ Windows. Повторный клик по выбранным — возврат прежних обоев и снятие обводки.
- «Добавить свои обои…» — выбор файла и установка на рабочий стол.
- Курсоры: настоящие курсоры Windows (системная схема), размер стандартный 32 px, курсор по центру картинки, без искажений качества, с анимацией там, где она есть в схеме. Повторный клик — возврат прежней схемы.
- Цвета: акцентный цвет Windows и режимы (тёмный/светлый, прозрачность) — для операционной системы. Повторный клик — возврат.
- Все тайлы одинакового размера на любом экране; сетка центрирована, без пустоты справа/слева.
- Не должно быть «Применение к Windows пока не подключено» — вместо этого кнопка работает.
- Обновлённые ресурсы: тайлы обоев и курсоров из старого репозитория (owner-3/ref-*.png для образца).

## Пасхалки и анимации

- Анимация нажатия на плитку и наведение — плавные, transform/opacity, без «линий, уходящих в сторону».

## Производительность

- Изменение размера окна мышкой не должно лагать.
- Тяжёлые страницы не перерисовываются при каждом изменении размера.

## Тонкий процесс работы

- Все ответы владельцу короткие; план исправлений — одним списком; без лишних вопросов, если решение очевидно.
- Исправления делаются пачкой; перед коммитом — тесты, svelte-check, сборка.
- Расход лимита: Sonnet для кода, Opus только для сложного.
