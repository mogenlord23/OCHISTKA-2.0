## Что НЕ входит в этот круг (и почему)

1. **Сборка libclamav под Windows** — отдельный этап. Сейчас движок в приложении отсутствует,
   и проверка честно это сообщает. Круг не должен это скрывать или обходить.
2. **Перенос находок в карантин** — запрещён на уровне команды
   (`apps/desktop/src-tauri/src/disks.rs:283`): безопасность переноса не доказана.
   Кнопка «убрать» в этом круге появляется, но выключена с понятной причиной.
3. **«Канарейки»** (фейковые папки с паролями и блокировка процессов) — только короткая
   записка `docs/status/virus-canaries.md`: идея, риски, что нужно для каждой ОС. Без кода.

## Цель

Один рабочий экран проверки: большая кнопка с анимацией, справа — находки с флажками,
внизу — векторная корзина, куда «слетаются» находки; правый клик по находке открывает папку.
Поведение файлов не меняется: ничего не удаляется и не переносится.

## Этапы

### T1. Каркас экрана «Проверка»

- Две колонки в подразделе `scan`: слева «станция» (иконка щита, состояние, кнопка), справа
  панель находок. Корзина — под станцией, прижата к низу колонки.
- Список находок вынести в `FindingsList.svelte` и использовать и в `scan`, и в `findings`
  (не дублировать разметку). В списке: путь, сигнатура, причина, подсказка подозрительности,
  флажок `Check` (`controlled`), счётчик выбранных.
- Корзина — `VirusBin.svelte`, inline SVG, простая векторная форма, без растровых картинок.
- Адаптив: < 980px — колонки друг под другом; < 720px — без горизонтальной прокрутки.
  Минимальное окно 900×520: всё помещается, прокрутка — только у списка находок.
- Только токены: `--radius-*`, цвета из `tokens.ts`; без теней; сетка 8px.

### T2. Анимации

- Кнопка: покой → наведение → нажатие (мгновенный отклик) → `scanning` (пульсация + луч) →
  результат (находки / чисто / не удалось проверить).
- Находки «слетаются» в корзину: 1–3 мелкие векторные фигуры, полёт 350–600 мс, затем крышка
  закрывается. Число на корзине = числу находок отчёта.
- `prefers-reduced-motion: reduce` **и** `:root[data-reduce-motion='true']`: без полёта,
  вращения и пульсации, состояния меняются мгновенно. Тест `reduced-motion.test.ts` обновить.
- Без библиотек анимации и новых зависимостей: CSS-переходы или Web Animations API.

### T3. Находки: выбор и правый клик

- ПКМ по находке открывает `ContextMenu`: «Открыть папку» и «Скопировать путь» (второй пункт —
  только если в проекте уже есть готовое копирование; иначе не делать).
- «Открыть папку» — родительская папка файла через `revealInExplorer`; ошибка показывается
  строкой по-человечески, без окон и кодов.
- Клавиатура: ряд находки фокусируется, меню вызывается с клавиатуры как в «Процессах».

### T4. Корзина и кнопка «Убрать выбранные»

- Кнопка рядом с корзиной, подпись владельца: «Убрать выбранные».
- Активна только когда перенос разрешён и выбрана хотя бы одна находка. Пока перенос запрещён,
  кнопка выключена, рядом короткая причина без технических слов: «Пока нельзя убрать: перенос
  файлов ещё не готов».
- Код переноса уже есть (`quarantineSelected` в `scanState.svelte.ts`): не дублировать, не
  менять его сейчас; при включённом переносе кнопка вызывает его, после успеха проигрывает
  «корзина выбрасывает» (крышка открывается, фигуры улетают, счётчик обнуляется).
- Подтверждающих окон не добавлять: перенос обратим (правило владельца).

### T5. Честные состояния

- Движок недоступен: на станции — короткая фраза простыми словами, техническую ссылку на
  `docs/status/clamav-build.md` показывать только в «Журнале».
- Проверка прошла, находок нет, но `report.errors > 0` или `incomplete` — писать «проверить
  не удалось» / «проверено не всё», а **не** «угроз не найдено».
- Пустая папка — «Проверять нечего».
- Каждое состояние покрыть тестом.

### T6. Документация

- `docs/status/round28.md`: решение владельца, что сделано, PASS / FAIL / NOT RUN, что
  осталось (движок Windows, перенос в карантин, канарейки), следующий шаг.
- `docs/platform-status.md`: строка про интерфейс проверки — Windows `implemented`,
  macOS и Linux `NOT RUN` (интерфейс общий, но приложение там не запускалось).
- `docs/status/virus-canaries.md`: идея канареек на 15–20 строк, с рисками и вопросами.

## Требования владельца (дословно, ничего не терять)

1. Одна большая кнопка с анимацией: нажал — ищет вирусы.
2. Корзина векторная, простая; вирусы залетают в неё, потом она закрывается.
3. Найденное показывается справа.
4. На каждой находке — галочка; выбрать можно вручную по одной.
5. Правый клик по находке — открыть папку, где она лежит.
6. Сначала ничего не удаляется.
7. Потом кнопка «удалить/убрать выбранные» — корзина выбрасывает накопленное, с анимацией.
8. Тексты простые, без техники.

## Не делать

- Не собирать libclamav, не включать фичу `libclamav`, не менять FFI и `unsafe`.
- Не включать перенос в карантин, не ослаблять проверки идентичности, не менять `disks.rs:283`.
- Не делать канарейки кодом.
- Не трогать другие разделы, оболочку, навигацию и подразделы (остаются три: Проверка,
  Находки, Журнал).
- Не добавлять зависимости, растры, сторонние иконки.
- Не добавлять «выбрать все», если владелец не просил.

## Критерии готовности

1. Экран «Проверка»: станция с большой кнопкой, список находок справа, корзина снизу; всё в
   токенах, без теней, сетка 8px.
2. Анимации работают и отключаются при `prefers-reduced-motion` и `data-reduce-motion`.
3. Флажки и счётчик выбранных верны; выбор сохраняется при переключении подразделов.
4. ПКМ открывает папку находки; ошибка объясняется простыми словами.
5. «Убрать выбранные» выключена с понятной причиной; логика включения готова к будущему
   переносу (без изменения самого переноса).
6. Нет состояний, где непроверенное выдаётся за «чисто».
7. `npm run check`, целевые тесты, `cargo fmt --all --check` — PASS.
