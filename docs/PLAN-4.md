# PLAN-4 — правки по отзыву пользователя (2026-11-19)

Главное правило: один радиус скругления везде (окно = карточки = кнопки = плитки), как в прошлой версии. Всё выровнено, одинаковые элементы — одного размера.

## Инструменты (экономно)
- `ui-design-review:ui-polish` — только на этапе F (сверка), один проход.
- `plugin:playwright` — снимки разделов для сверки (deviceScaleFactor 1).
- Не используем: audit, code-review max, figma, vercel, параллельные агенты.

## A. Общий стиль
- [x] Вернуть скругление окна как в прошлой версии; один токен `--radius` для всего приложения (VPN-плитки, кнопки, карточки, драйверы).
- [x] Убрать сильную тень окна (как раньше — без тени).
- [x] Один общий компонент чекбокса (как в «Оформление → Цвета») для всех разделов, включая VPN → Маршруты; без лишнего левого отступа.
- [x] Заголовок «ОЧИСТКА» вернуть на прежнюю позицию (выровнять).
- [x] Звук клика при переходе между разделами (когда «звук включён»), как в старой версии.
- [x] Всплывающая подсказка у иконок панели: непрозрачный фон, не просвечивает выбранный раздел.
- [x] Клик по персонажу в VPN: анимация и звук «хихи» мгновенно (предзагрузка аудио).

## B. Оформление
- [x] Курсоры: убрать крутящуюся анимацию превью; выбор — просто клик и обводка.
- [x] Курсоры: исправить «не удалось работать с реестром. Операция успешно завершена» (код 0 считать успехом).
- [x] Обои: убрать одноцветные; сделать 4 кислотных на фоне приложения + чёрный, белый, красный (7 шт.).
- [x] «Вернуть оформление Windows» — обычная кнопка без чекбокса.
- [x] «Залить панель задач» и «Эффект прозрачности» — взаимоисключающие (выбор одного скрывает другой); убрать лаги (debounce, без перерисовки).

## C. Компьютер
- [x] Настройки: убрать предупреждения-подтверждения (прозрачность и др.) — применять сразу (откат сохраняется).
- [x] Драйверы: убрать кнопку «Все»; повторный клик по плитке снимает фильтр.
- [x] Драйверы: все плитки (NVIDIA, AMD, Realtek, Wi-Fi, USB…) квадратные одного размера.
- [x] Драйверы: выбранная плитка обводится белым, как обои/курсоры.
- [ ] Драйверы: проверить ссылки производителей, исправить неверные.

- [x] Программы: по умолчанию сортировка по размеру, убывание.

## E. VPN
