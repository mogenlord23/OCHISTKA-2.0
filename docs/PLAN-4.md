# PLAN-4 — правки по отзыву пользователя (2026-11-19)

Главное правило: один радиус скругления везде (окно = карточки = кнопки = плитки), как в прошлой версии. Всё выровнено, одинаковые элементы — одного размера.

## Инструменты (экономно)
- `ui-design-review:ui-polish` — только на этапе F (сверка), один проход.
- `plugin:playwright` — снимки разделов для сверки (deviceScaleFactor 1).
- Не используем: audit, code-review max, figma, vercel, параллельные агенты.

## A. Общий стиль
- [ ] Вернуть скругление окна как в прошлой версии; один токен `--radius` для всего приложения (VPN-плитки, кнопки, карточки, драйверы).
- [ ] Убрать сильную тень окна (как раньше — без тени).
- [ ] Один общий компонент чекбокса (как в «Оформление → Цвета») для всех разделов, включая VPN → Маршруты; без лишнего левого отступа.
- [ ] Заголовок «ОЧИСТКА» вернуть на прежнюю позицию (выровнять).
- [ ] Звук клика при переходе между разделами (когда «звук включён»), как в старой версии.
- [ ] Всплывающая подсказка у иконок панели: непрозрачный фон, не просвечивает выбранный раздел.
- [ ] Клик по персонажу в VPN: анимация и звук «хихи» мгновенно (предзагрузка аудио).

## B. Оформление
- [ ] Курсоры: убрать крутящуюся анимацию превью; выбор — просто клик и обводка.
- [ ] Курсоры: исправить «не удалось работать с реестром. Операция успешно завершена» (код 0 считать успехом).
- [ ] Обои: убрать одноцветные; сделать 4 кислотных на фоне приложения + чёрный, белый, красный (7 шт.).
- [ ] «Вернуть оформление Windows» — обычная кнопка без чекбокса.
- [ ] «Залить панель задач» и «Эффект прозрачности» — взаимоисключающие (выбор одного скрывает другой); убрать лаги (debounce, без перерисовки).

## C. Компьютер
- [ ] Настройки: убрать предупреждения-подтверждения (прозрачность и др.) — применять сразу (откат сохраняется).
- [ ] Драйверы: убрать кнопку «Все»; повторный клик по плитке снимает фильтр.
- [ ] Драйверы: все плитки (NVIDIA, AMD, Realtek, Wi-Fi, USB…) квадратные одного размера.
- [ ] Драйверы: выбранная плитка обводится белым, как обои/курсоры.
- [ ] Драйверы: проверить ссылки производителей, исправить неверные.

## D. Процессы и Программы
- [ ] Процессы: по умолчанию сортировка по CPU, убывание.
- [ ] Программы: по умолчанию сортировка по размеру, убывание.

## E. VPN
- [ ] Убрать техническое «ядро не установлено» из интерфейса (ставить ядро молча или скрыть строку).

## F. Проверка
- [ ] Тесты точечно + снимки разделов, сверка радиусов/отступов, итог в docs/status/итог-4.md.
