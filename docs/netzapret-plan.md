# Сетевые возможности OCHISTKA: сопоставление с NetZapret и план

Источник ориентира: README проекта NetZapret (https://github.com/RixyPow/netzapret, лицензия MIT). Интерфейс и код оттуда не копируем.

## Как теперь устроено «VPN → Дополнительно» (этап 6А)
Одна карточка на понятную задачу, внутри скрыта вся техника:
1. **Обход блокировок** — один выключатель (сайты, Telegram, Discord, игры). Пока недоступен: честный статус «Выключено · недоступно».
2. **DNS** — выключатель и кнопка «Выбрать» (фирменное меню: «Автоматически» отмечено; Cloudflare, Google, OpenDNS, Quad9 показаны недоступными). Системный DNS не меняется.
3. **Маршруты и исключения** — прежний блок без изменений (старый формат данных сохранён).
«Zapret» и «Xbox DNS» переименованы и не дублируются; отдельной карточки Telegram нет.

## Сопоставление возможностей
| Возможность NetZapret | Что есть в OCHISTKA | Состояние |
|---|---|---|
| Десинк (Zapret 2 / winws2) для сайтов, Discord, игр | карточка «Обход блокировок» | интерфейс готов, движка нет |
| Прокси для Telegram Desktop | входит в «Обход блокировок» | не реализовано |
| VPN (sing-box), подписки, замер задержек | вкладка VPN | работает |
| Маршруты: напрямую, VPN, десинк | «Маршруты и исключения» (напрямую и VPN работают) | «через обход» появится с движком |
| DNS: резолверы, путь DNS | карточка «DNS» | интерфейс готов, применения нет |
| Пины в hosts | нет | позже, отдельно от DNS |
| Проверка блокировок, подбор стратегии | нет | после десинка |
| Диагностика соединений | вкладка «Соединения» (TCP), «Сеть» | частично |
| WARP как запасной вариант | нет | позже |

## Лицензии (важно для OCHISTKA на Rust + Tauri)
- Zapret 2 / winws2 — MIT: можно поставлять отдельным процессом с уведомлением.
- WinDivert (перехват пакетов для winws2) — LGPL v3 / GPL v2: только отдельным файлом (DLL и драйвер), без статической линковки; нужны текст лицензии и ссылка на исходники. Драйвер требует прав администратора и подписи.
- sing-box — GPL v3: уже запускается отдельным процессом, это сохраняем.
- Wintun — проприетарная, нужна только для TUN: пока не берём.
- dnscrypt-proxy — ISC (шифрованные резолверы, если решим добавить), tg-ws-proxy-rs — MIT.
Итог по лицензиям пока записывается в THIRD-PARTY.md (лицензия OCHISTKA — TBD, как и для ClamAV/GPL-2.0).

## Конфликты стратегий (принцип выбора)
Пресеты Universal и сообщества не складываем. Один активный «профиль десинка» на запуск; выбор автоматический:
1. Профиль выбирается из закреплённого набора, а не собирается из правил разных пресетов.
2. У каждого профиля есть «покрытие» (сайты, Discord, игры). Если нужно больше покрытия, берётся профиль, который его включает, а не второй процесс.
3. Два экземпляра winws2 с пересекающимися фильтрами не запускаются: перед стартом проверка пересечения портов и фильтров.
4. Подбор — по результатам проверки блокировок (после включения основного режима), с откатом на предыдущий профиль при ухудшении.

## Следующий этап (6Б): рабочий десинк одной кнопкой
1. **Движок.** Файлы winws2 + WinDivert поставляются с закреплёнными SHA-256 (как sing-box); загрузка только с GitHub Releases по https; без установки служб.
2. **Права.** Администратор запрашивается один раз для запуска (не для всего приложения); отказ показывается понятной фразой.
3. **Один профиль.** Закрепить один проверенный профиль «Сайты и Discord», запуск только по включению, остановка при выключении, выходе и аварии (как у sing-box: файл номера процесса, очистка при старте).
4. **Проверка.** После запуска проверка доступности контрольных сайтов; статус «Включено» только при подтверждении, иначе откат и причина.
5. **Совместимость с VPN.** Пока VPN подключён, десинк работает только для трафика мимо туннеля; конфликтующий запуск блокируется с понятным сообщением.
6. **Тесты.** Поддельный хозяин процесса (как `FakeHost`), тесты отката, повторного запуска и очистки; реальная проверка только на Windows скриптом по образцу `tools/vpn-check-windows.ps1`.
Затем: Telegram-прокси, DNS-резолверы, проверка блокировок, режим маршрута «через обход».

## Этап 6Б.1: что подготовлено (без включения)
- `crates/ochistka-core/src/desync.rs`: управление движком через порт `DesyncHost` — проверка наличия, подготовка закреплённых компонентов, запуск только по явному вызову, проверка, что процесс жив, остановка, защита от второго экземпляра, очистка остатков после аварии, отказ при работающем VPN, запрос прав администратора только в точке запуска. Проверено тестами на подставном процессе (Linux).
- Общая проверка адреса и SHA-256 с sing-box: `PinnedEngine` получил `url_prefix`.
- **Не подтверждено и потому не включено:** (1) хэши и версии официальных файлов — из Cloud GitHub-релизы недоступны (403), закрепление после запуска `tools/desync-core/verify-sources.ps1` на Windows; (2) аргументы профиля «Сайты и Discord» — придумывать нельзя, нужна проверка на Windows; `pinned()` и `site_discord_profile()` пока возвращают `None`, поэтому ничего не скачивается и не запускается.
- Не сделано: адаптер Windows (`crates/platform`: запуск, определение прав, остановка по имени `winws2.exe`), подключение к команде Tauri и к переключателю.

## Результат проверки на Windows (6Б.1)
Первый запуск `verify-sources.ps1` (старая версия, скачивала архив): **Защита Windows заблокировала архив Zapret 2 v1.0.7**
(«файл содержит вирус или потенциально нежелательное ПО») — это известное срабатывание на инструменты обхода DPI и перехват пакетов.
Выводы: защиту не отключаем и исключения не добавляем; скрипт теперь ничего не скачивает и берёт только контрольные суммы из данных GitHub.
Риск для продукта: приложение, которое само скачивает и распаковывает `winws2` и WinDivert, будет блокироваться защитой Windows у пользователей.
Решение (отдельное, за пользователем): оставить обход блокировок опциональным компонентом с честным сообщением «защита Windows заблокировала файл» либо отказаться от встроенного движка.

## Архитектура на три ОС (заменяет Windows-ориентированные пункты выше)
OCHISTKA кроссплатформенная: Windows, macOS, Linux. Сетевая подсистема делится на общее ядро и системные адаптеры.

**Общее ядро** (`crates/ochistka-core/src/desync.rs`, без обращений к ОС):
- `Platform`, `Engine` (`Winws2` — Windows, `Nfqws2` — Linux, на macOS движка нет), `Coverage` (сайты, Discord, Telegram, игры).
- `Strategy` и `select_strategy`: из стратегий движка выбирается ОДНА, целиком охватывающая нужное, с наименьшим лишним охватом. Пресеты Universal и сообщества подключаются как отдельные стратегии, складывать их нельзя; если подходящей нет, обход не включается.
- `DesyncService`: запуск только по явному действию, проверка процесса, остановка, защита от второго экземпляра, очистка после аварии, отказ при работающем sing-box, отказ при неготовом адаптере.
- `Readiness` (`Ready` / `NotImplemented` / `Unsupported`): переключатель показывает «работает» только при `Ready`.

**Системный адаптер** (`DesyncAdapter`, по одному на ОС в `crates/platform`): `platform`, `readiness`, `locate`, `install` (закреплённые SHA-256, только с официальных источников), `has_privileges`, `spawn`, `kill_stale`. Пока используется `UnavailableAdapter`: честно сообщает причину и ничего не запускает.

**Что нужно дальше по ОС**
- *Windows*: адаптер `winws2` + WinDivert (права администратора только в точке запуска; Defender блокирует архив, защиту не отключаем: см. выше). Закрепить хэши и аргументы профиля после проверки на Windows.
- *Linux*: адаптер `nfqws2` + NFQUEUE (nftables/iptables), права root или CAP_NET_ADMIN запрашиваются в точке запуска (polkit), без постоянных служб; подтвердить сборки, лицензию (MIT) и хэши; правила файрвола ставятся временно и снимаются при остановке и после аварии.
- *macOS*: Zapret 2 как движок не заявляем. Исследовать (не подтверждено): системный прокси через `networksetup` (как у sing-box), Network Extension (нужна подписанная учётная запись разработчика и права), `pf` с прозрачным прокси. Gatekeeper и подпись не обходим; любой бинарный файл должен быть подписан и нотаризован. До результата исследования `Readiness::Unsupported`.

**Что общее в интерфейсе**: одна карточка «Обход блокировок» с одним переключателем на всех ОС; недоступность объясняется по `Readiness`, без имитации работы. sing-box и системный прокси остаются как есть.
**Источники для переиспользования**: NetZapret (MIT) — правила, сервисы, подбор; Zapret 2 (MIT) — стратегии/пресеты, `winws2`/`nfqws2`. Из Cloud файлы репозиториев напрямую недоступны, поэтому конкретные пресеты и аргументы берём только после проверки на целевой ОС.
