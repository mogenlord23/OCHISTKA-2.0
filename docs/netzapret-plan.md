# Сетевые возможности OCHISTKA: сопоставление с NetZapret и план

Источник ориентира: README проекта NetZapret (https://github.com/RixyPow/netzapret, лицензия MIT). Интерфейс и код оттуда не копируем.

## Как теперь устроено «VPN → Дополнительно» (этап 6А)
Одна карточка на понятную задачу, внутри скрыта вся техника:
1. **Обход блокировок** — один выключатель (сайты, Telegram, Discord, игры). Пока недоступен: честный статус «Выключено · недоступно».
2. **DNS** — выключатель и кнопка «Выбрать» (фирменное меню: «Автоматически» отмечено; Cloudflare, Google, OpenDNS, Quad9 показаны недоступными). Системный DNS не меняется.
3. **Маршруты и исключения** — прежний блок без изменений (старый формат данных сохранён).
«Zapret» и «Xbox DNS» переименованы и не дублируются; отдельной карточки Telegram нет.

## Сопоставление возможностей
| Возможность NetZapret | Что есть в OCHISTKA | Состояние |
|---|---|---|
| Десинк (Zapret 2 / winws2) для сайтов, Discord, игр | карточка «Обход блокировок» | интерфейс готов, движка нет |
| Прокси для Telegram Desktop | входит в «Обход блокировок» | не реализовано |
| VPN (sing-box), подписки, замер задержек | вкладка VPN | работает |
| Маршруты: напрямую, VPN, десинк | «Маршруты и исключения» (напрямую и VPN работают) | «через обход» появится с движком |
| DNS: резолверы, путь DNS | карточка «DNS» | интерфейс готов, применения нет |
| Пины в hosts | нет | позже, отдельно от DNS |
| Проверка блокировок, подбор стратегии | нет | после десинка |
| Диагностика соединений | вкладка «Соединения» (TCP), «Сеть» | частично |
| WARP как запасной вариант | нет | позже |

## Лицензии (важно для OCHISTKA на Rust + Tauri)
- Zapret 2 / winws2 — MIT: можно поставлять отдельным процессом с уведомлением.
- WinDivert (перехват пакетов для winws2) — LGPL v3 / GPL v2: только отдельным файлом (DLL и драйвер), без статической линковки; нужны текст лицензии и ссылка на исходники. Драйвер требует прав администратора и подписи.
- sing-box — GPL v3: уже запускается отдельным процессом, это сохраняем.
- Wintun — проприетарная, нужна только для TUN: пока не берём.
- dnscrypt-proxy — ISC (шифрованные резолверы, если решим добавить), tg-ws-proxy-rs — MIT.
Итог по лицензиям пока записывается в THIRD-PARTY.md (лицензия OCHISTKA — TBD, как и для ClamAV/GPL-2.0).

## Конфликты стратегий (принцип выбора)
Пресеты Universal и сообщества не складываем. Один активный «профиль десинка» на запуск; выбор автоматический:
1. Профиль выбирается из закреплённого набора, а не собирается из правил разных пресетов.
2. У каждого профиля есть «покрытие» (сайты, Discord, игры). Если нужно больше покрытия, берётся профиль, который его включает, а не второй процесс.
3. Два экземпляра winws2 с пересекающимися фильтрами не запускаются: перед стартом проверка пересечения портов и фильтров.
4. Подбор — по результатам проверки блокировок (после включения основного режима), с откатом на предыдущий профиль при ухудшении.

## Следующий этап (6Б): рабочий десинк одной кнопкой
1. **Движок.** Файлы winws2 + WinDivert поставляются с закреплёнными SHA-256 (как sing-box); загрузка только с GitHub Releases по https; без установки служб.
2. **Права.** Администратор запрашивается один раз для запуска (не для всего приложения); отказ показывается понятной фразой.
3. **Один профиль.** Закрепить один проверенный профиль «Сайты и Discord», запуск только по включению, остановка при выключении, выходе и аварии (как у sing-box: файл номера процесса, очистка при старте).
4. **Проверка.** После запуска проверка доступности контрольных сайтов; статус «Включено» только при подтверждении, иначе откат и причина.
5. **Совместимость с VPN.** Пока VPN подключён, десинк работает только для трафика мимо туннеля; конфликтующий запуск блокируется с понятным сообщением.
6. **Тесты.** Поддельный хозяин процесса (как `FakeHost`), тесты отката, повторного запуска и очистки; реальная проверка только на Windows скриптом по образцу `tools/vpn-check-windows.ps1`.
Затем: Telegram-прокси, DNS-резолверы, проверка блокировок, режим маршрута «через обход».
