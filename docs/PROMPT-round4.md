# Задание: круг 4 (замечания по скриншотам Компьютер → Настройки / Boost и др.)

Приоритет выше старых решений там, где они противоречат. Общие правила — docs/PROMPT-round3.md и CLAUDE.md (токены скруглений, без окон-предупреждений в обычных действиях, мгновенный выбор, честность «implemented / verified»).

## Этапы (по одному помощнику, по порядку)
S1. Новый переключатель + Настройки + Boost (реальные эффекты, компактная структура).
S2. Процессы (расположение файла, службы с управлением, высота списка), Программы (открыть папку), автозагрузка (высота).
S3. VPN: «Маршруты и исключения» внутрь «Дополнительно»; переключатели Zapret / Xbox DNS; ошибка HTTP 410 при импорте; тест скорости в «Сеть».
S4. Оболочка и оформление: мгновенный «Компьютер», звук (мягкий ASMR-щелчок), блок «Звук/RU/ENG» непрозрачный на минимальном окне, чёрная рамка на миниатюрах обоев, задержка курсоров, драйверы «Звук и связь» вместо отдельного Realtek.

## 1. Общее
- Раздел «Компьютер» показывает структуру сразу, данные грузятся в фоне (последние значения из кэша, обновление по готовности). Никакого пустого экрана «Загрузка».
- Переход между разделами визуально мгновенный; рывки окна; лишние перерисовки и повторные обращения к Windows убрать.
- Переключатели: убрать нарисованную галочку. Новый компонент Switch.svelte: пилюля в стиле кнопки подключения VPN (выкл — тёмная с белой обводкой, ручка слева; вкл — фирменная кислотная заливка, ручка справа; анимация ~160 мс, одинаково для всех). Состояния: выкл, вкл, ожидание (ручка пульсирует), ошибка (откат + короткая фраза). Выбор карточек — белая обводка. Разовое действие — обычная кнопка. Размер соразмерен тексту (высота ~24 px). Check.svelte заменить на Switch везде, где это «включить/выключить»; Check оставить только для множественного выбора в списках (например, категории очистки дисков), без галочки: заливка/обводка в тон. Решение записать в docs/adr/0012-switch.md.

## 2. Нижняя панель «Звук / RU / ENG»
Раскрытый блок полностью непрозрачный и выше всего по слоям, на минимальном размере окна тоже (сейчас просвечивает активная плитка «Оформление»).

## 3. Звук
Заменить click/switch на мягкий короткий тактильный щелчок ASMR: низкий тёплый, 20–40 мс, тихий, без металла (синтез: затухающий шум + низкий синус ~180–260 Гц, мягкая атака, нормализация -18 dBFS). Переход между разделами — чуть мягче/ниже. Воспроизведение без задержки (предзагрузка). Общий переключатель звука сохраняется.

## 4. Оформление
- Курсоры: выделение мгновенно; системное применение вынести из пути интерфейса; найти причину задержек (синхронная запись 17 ролей, генерация .cur/.ani в обработчике клика, рассылка), кэшировать готовые файлы схемы, генерировать заранее в фоне; наведение на карточки без подлагиваний (никаких тяжёлых hover-эффектов).
- Обои: убрать тонкую чёрную рамку у миниатюр (фон контейнера, border, кадрирование, скругление изображения через тот же токен, object-fit: cover, display:block).

## 5. Компьютер → Настройки
Компактная структура: группы-секции со сворачиваемым заголовком, строки (название + короткое описание + переключатель) вместо огромных карточек; служебную строку «Исходное состояние сохраняется перед применением» показывать один раз вверху раздела, не в каждой строке. Поиск по настройкам вверху и навигация по категориям. Категории и пункты (все сохранить, не терять функции):
- Внешний вид и рекомендации Windows: убрать прозрачность Windows; советы на экране блокировки; размытие при входе; виджеты на панели задач; меньше персональных предложений; дополнительные подсказки Windows; рекламные предложения; рекомендации в «Пуске»; не предлагать новый Outlook.
- Поиск Windows: веб-подсказки в поиске; «интересное» в поиске; облачный поиск (три разных системных действия, показывать отдельными строками в одной группе).
- Конфиденциальность и диагностика: минимум диагностики; рекламный ID; геолокация приложений; отчёты об ошибках; запросы отзывов; снимки Recall; камера; микрофон; контакты для приложений.
- Microsoft Edge: не оставлять в фоне; не отправлять сведения о сайтах; персональная реклама; предложения поиска; не сохранять новые пароли; боковая панель и Copilot.
- Системные компоненты и облако: Cortana (если есть); Windows Copilot (где поддерживается); синхронизация OneDrive; синхронизация параметров профиля.
- Обновления Windows: спрашивать перед загрузкой; не перезагружать при активном сеансе.
- Информационный блок «Активация Windows»: реальный статус (slmgr /xpr через C:\Windows\System32\cscript.exe или WMI SoftwareLicensingProduct.LicenseStatus) и кнопка перехода к ms-settings:activation. Не переключатель.
Реальная работа: для КАЖДОГО параметра — ключ реестра/политика, поддерживаемые версии Windows 10/11, чтение исходного и итогового значения, откат. Состояние «включено» показывать только после успешного применения (оптимистичный показ при ошибке откатывается с короткой причиной). Не поддерживается версией — строка серым с причиной, не ложный успех. Известный баг: «Убрать веб-подсказки из поиска» ничего не делает — на Win 10/11 нужны HKCU\Software\Policies\Microsoft\Windows\Explorer DisableSearchBoxSuggestions=1 и HKCU\Software\Microsoft\Windows\CurrentVersion\Search BingSearchEnabled=0 (+ перезапуск Проводника/поиска не нужен для новых окон; указать «вступит в силу после выхода из системы / перезапуска Проводника» там, где так). Сверить остальные ключи по документации Microsoft и записать таблицу «параметр → ключ → версии» в docs/status/settings-keys.md.

## 6. Компьютер → Boost
- Игровые профили Базовый / Игровой / Максимум — взаимоисключающие (сегмент-переключатель, один активен), отдельно от отдельных оптимизаций.
- Отдельные оптимизации (переключатели): убрать фоновую запись игр (Game DVR); без ограничения фоновой мощности (Power Throttling); Ultimate Performance (powercfg по абсолютному пути C:\Windows\System32\powercfg.exe, запоминать прежнюю схему); планирование GPU (HAGS); игровой режим Windows; игровой режим без VBS/HVCI.
- Кратко: что меняет и нужен ли перезапуск. Опасное автоматически не включать.
- Баг: «Убрать фоновую запись игр» не работает: проверить ключи (HKCU\System\GameConfigStore GameDVR_Enabled=0, HKCU\Software\Microsoft\Windows\CurrentVersion\GameDVR AppCaptureEnabled=0, политика HKLM\SOFTWARE\Policies\Microsoft\Windows\GameDVR AllowGameDVR=0 — HKLM только по отдельному запросу администратора), читать состояние до/после, откат; различия Win10/11.
- VBS/HVCI: единственное действие с явным подтверждением и объяснением последствий и откатом (остаётся диалог только здесь).

## 7. VPN
- Убрать вкладку «Маршруты и исключения» из основной навигации; внутрь «Дополнительно» блоки «Маршруты» и «Исключения» с пояснениями (что через VPN, что напрямую). Функционал не удалять.
- Zapret и Xbox DNS: Switch с состояниями выкл/вкл/ожидание/ошибка; успех показывать только после проверки (если функция пока не реализована — Switch выключен и недоступен с честной причиной, не имитировать).
- Импорт подписки: пользователь получил HTTP 410 для ссылки сервиса «Tultem.app». Проверить запрос (redirects, заголовки, User-Agent как в 0.5.5, повтор с другим UA), различия с 0.5.5. 410 по смыслу «ссылка удалена/недействительна» — если сервер так отвечает, не притворяться: показать «Ссылка больше не действует. Обновите её в личном кабинете сервиса», без кода. Ссылки и токены подписки не писать в логи (маскировать).
- «Сеть»: тест скорости рядом с «Твой интернет»: кнопка, Download, Upload, Ping, задержка под нагрузкой и стабильность (джиттер), анимированный индикатор в фирменных цветах, плавная скорость, карточки результатов, итог, адаптив к маленькому окну. Только по нажатию, не блокирует интерфейс, отмена и повтор, понятная ошибка без интернета, предупреждение один раз «Тест расходует трафик и обращается к серверу измерения». Сервер: Cloudflare speed endpoints (https://speed.cloudflare.com/__down?bytes=N и /__up) — https, без личных данных. Реализовать в Rust (reqwest, потоки с отменой), результат через Channel.

## 8. Драйверы
Убрать отдельную карточку Realtek; категория «Звук и связь»: Realtek Audio, Realtek LAN/Wi-Fi, другие аудио, Wi-Fi, Bluetooth; внутри — производитель, тип устройства, официальный драйвер. Иконка категории. Перед установкой определять оборудование, версию Windows, совместимость.

## 9. Процессы, службы, программы
- Процессы: кнопка «Расположение файла» реально открывает Проводник с выделением файла (C:\Windows\explorer.exe /select,"путь"), путь через sysinfo exe(); нет прав/системный — понятная причина; без зависаний.
- Службы: управление — запуск, остановка, тип запуска (авто/вручную/отключено) через безопасный механизм (windows-service/ windows crate, SCM; без unsafe вне win32_ffi.rs; либо C:\Windows\System32\sc.exe по абсолютному пути с разбором вывода). Фактическое состояние и результат операции; права администратора только для действия (повышение через отдельный запуск), защищённые и критичные службы (список белого/чёрного) не менять; опасные — с явным подтверждением и последствиями. Снять надпись «только для чтения».
- Высота списков служб, процессов и автозагрузки: заполняют всю высоту до низа, внутренняя прокрутка, строки не растягивать, не обрезаются нижней панелью, проверить на минимальном окне.
- Программы: путь установки — действие «Показать в Проводнике» по нажатию на путь/кнопку (не по наведению); нет пути — объяснение.

## Проверка каждого этапа
Реальная работа, а не только вид; мгновенный отклик; чтение/применение/откат состояния Windows; согласованность с дизайн-системой; минимальный размер окна без перекрытий; честный статус «implemented / verified на Windows»; целевые тесты; отдельные коммиты.
