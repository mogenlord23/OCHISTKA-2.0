# Требования владельца (читать в начале каждой сессии)

Владелец не программист. Все промпты для Sonnet должны учитывать пункты ниже.

## Цель продукта
OCHISTKA — одно универсальное приложение для Windows, macOS и Linux: очистка, процессы, программы, диски, VPN, оформление и обход сайтов. Один код, одна кнопка на функцию. Установил — всё работает, без лишних окон.

## Правила работы
1. **Владелец не программист.** Не перекладывать на него техническую работу. Команды PowerShell — только для проверки, с пошаговой инструкцией.
2. **Экономия лимита.** Промпты точные: пути к файлам, команды проверки, один результат на задачу. Один скилл на задачу. Точечные тесты, полный набор — только в конце этапа. Без субагентов. Короткий отчёт без пересказа кода. Не читать весь репозиторий.
3. **Ветка** `claude/optimistic-hypatia-hgstjj`. `main` не трогать. Без force-push.
4. **Тесты и запуск — через PowerShell владельца** (`cargo test`, `npm test`, `npm run dev`). Установщик на GitHub собирается только вручную (автосборка при push отключена, коммит `7e2ceb2`).
5. **Скиллы** (вызываются вручную, по одному на задачу): `/ochistka-feature`, `/ochistka-ui`, `/ochistka-visual-guard`, `/ochistka-performance`, `/ochistka-security`, `/ochistka-verify`, `/ochistka-vpn`.
6. **Удалять то, что владелец одобрил.** Устаревшие файлы старого обхода (SonicDPI, WinDivert-драйвер) удалять без возражений. Запреты — только для защиты: личные данные владельца, сеть и системные настройки без его решения, запуск исполняемых файлов на его компьютере из среды Sonnet.
7. **Тексты для пользователя простые,** без слов «замер», «служба», «порт», «SHA», «пресет», «движок», «драйвер» (кроме фразы про перезагрузку).
8. **Интерфейс:** одна кнопка, без панелей, галочек и подтверждений. Переключение мгновенное. Ничего не работает в фоне, когда выключено. Исключение по решению владельца: задержки серверов обновляются раз в 15 секунд, пока открыт раздел VPN (включён он или нет). Без автозапуска.
9. **VPN и обход взаимно выключают друг друга.** VPN не трогать; его логика общая для всех систем, отличаются только маленькие адаптеры.
10. **Одна кодовая база.** Логика — в `crates/ochistka-core`, системные вещи — в `crates/platform/src/<windows|macos|linux>`. macOS и Linux — отдельные этапы позже.
11. **Права администратора — один раз при установке,** не при каждом включении.
12. **Честность.** Не показывать «работает», пока не проверено. Не объявлять обход рабочим без проверки владельцем.
13. **Лицензии.** MIT и Apache-2.0 можно использовать с указанием авторов в `THIRD-PARTY.md`.
14. **Сайты.** Список доменов, без IP-адресов. Сейчас в `assets/sites/builtin.txt` 142 домена. Владелец расширяет список сам.
15. **Отдельный обход приложений (Discord desktop, Steam, Riot) не делаем** — решение владельца.
16. **Telegram Desktop через системный прокси не работает.** Его домены в списке могут помочь только в веб-версии.

## Текущее состояние (на момент записи)
- Обход сайтов: локальный прокси и системный прокси. Порядок включения исправлен. Тесты прокси проходят на Windows. В реальной сети сайты пока не открываются (проверено владельцем).
- Старый обход (SonicDPI, WinDivert) удалён.
- Этап 12 (служба Windows, права администратора один раз при установке) в работе.
- Тесты антивируса на Windows падают (вероятно, Defender удаляет тестовый файл EICAR). На обход не влияет.
