## 2. Курсоры

Курсоры изменения размера тоньше и длиннее, пропорции согласовать со схемой; все состояния ожидания и фоновой работы (Wait, AppStarting) анимированы в одном стиле; при автопрокрутке (колёсико-«якорь») иногда стандартный курсор — добавить роли ScrollNS/ScrollEW/ScrollNEW/ScrollNW/ScrollSE… (Pin, Person, ScrollAll и т.д.: покрыть все ключи HKCU\Control Panel\Cursors, которые Windows поддерживает: Arrow, Help, AppStarting, Wait, Crosshair, IBeam, NWPen, No, SizeNS, SizeWE, SizeNWSE, SizeNESW, SizeAll, UpArrow, Hand, Pin, Person, и ScrollAll/ScrollN/ScrollS/ScrollW/ScrollE/ScrollNW/ScrollNE/ScrollSW/ScrollSE там, где значения поддерживаются — проверить документацию), единый стиль. В карточках выбора — без анимации и вращения. Версию кэша CURSOR_RENDER_VERSION повысить.

## 3. Оформление → Цвета
Три элемента в ОДНУ горизонтальную линию слева направо: «Эффект прозрачности» (Switch), «Залить панель задач и Пуск» (Switch), «Вернуть оформление Windows» (кнопка). Каждый в своей чёрной карточке/кнопке с одинаковыми скруглением (токен), высотой, отступами, чёрным фоном. Стиль как у вкладок «Обои / Курсоры / Цвета» с понятным отличием от вкладок. На минимальном окне без наложений (адаптивная ширина, компактные отступы, flex-wrap запрещён — сжимать текст/отступы). Без квадратиков с галочками.
Мигание палитры при включении «Залить панель задач»: палитра не пересоздаётся (стабильные ключи, нет {#key}, нет повторной загрузки состояния, выбранный цвет сохраняется), реакция переключателя сразу, системное применение без блокировки, при ошибке откат.

## 4. Плавная смена фонового цвета между разделами
Как в старой OCHISTKA: при смене раздела цвет фона плавно перетекает (~320–400 мс, ease-out). Анимировать только общий фон (CSS-переменная через @property <color> или два слоя с opacity/transform; без перерисовки карточек и текста). Текстура сохраняется во время перехода, никаких белых/чёрных вспышек, быстрые переключения — идём к последнему цвету без очереди, prefers-reduced-motion — мгновенно. Цвета разделов — существующие фирменные.

## 5. Выделение текста

## 7. Компьютер → Настройки
7.1 Прыжки страницы при переключении в группе «Внешний вид и рекомендации»: стабильные ключи, не пересоздавать список, сохранять scrollTop и фокус, не менять высоту без нужды (резерв места под сообщение об ошибке/пояснение). Проверить на малом и большом окне.
7.2 Не работают: «Убрать рекомендации в Пуске» (возвращается), «Отключить рекламный ID», и другие дают «Не получилось изменить настройку». Для КАЖДОЙ проверить ключ, тип значения (DWORD/SZ), расположение (HKCU/HKLM, политики), поддержку редакций/версий. Известно: Start recommendations — HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced: Start_IrisRecommendations=0, Start_AccountNotifications=0, плюс политика HKLM\SOFTWARE\Policies\Microsoft\Windows\Explorer HideRecentlyAddedApps/…; на Win11 22H2+ учесть Start_TrackProgs; Windows может перезаписать значение, если ключ в политике — читать обратно через небольшую паузу и объяснять реальную причину. Advertising ID: HKCU\Software\Microsoft\Windows\CurrentVersion\AdvertisingInfo Enabled=0 (ключ может не существовать — создавать), политика HKLM\SOFTWARE\Policies\Microsoft\Windows\AdvertisingInfo DisabledByGroupPolicy=1 (админ). Разобрать причину «Не получилось изменить настройку»: показывать понятную причину из ошибки (нет прав, ключ защищён политикой, не поддерживается), не общий текст; в тестах покрыть создание отсутствующих ключей и перезапись политикой. Обновить docs/status/settings-keys.md.
7.3 Убрать поле «Найти настройку» и верхнюю навигацию по категориям (чипы, «Microsoft Edge»). Оставить кнопки «Вернуть изменения» (восстанавливает значения, сохранённые до изменений через OCHISTKA) и «Обновить состояние» (перечитывает без изменений). Группы-категории в списке сохранить.
