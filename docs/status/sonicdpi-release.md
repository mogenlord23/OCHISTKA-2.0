## Подпись

README называет релизы «подписанными», но в `release.yml` шага подписи нет (только архивы и `SHA256SUMS.txt`). Подпись кода **не подтверждена**.

## Вывод

- Готовые сборки Windows x64, Linux x64 и macOS заявлены в README и собираются GitHub Actions в самом репозитории SonicDPI; реальное наличие файлов на странице релизов не проверено.
- Сборка локально: **не требуется** (если релиз с файлами существует; иначе собрать на GitHub Actions в форке, не локально).
- Перед использованием владелец открывает страницу релизов, сверяет имена, размер и SHA-256 из `SHA256SUMS.txt`; только после этого значения заносятся в этот файл.
