# ochistkadpi: запуск с правами администратора и статус кнопки

Дата: 2026-11-21. Не проверено на Windows: UAC, настоящий запуск, журнал, остановка.

## Как работает кнопка «Обход блокировок»

1. Нажатие: VPN при необходимости отключается, затем адаптер запускает `ochistkadpi.exe run --profile youtube-discord`.
2. Если приложение не администратор, Windows показывает запрос прав (`ShellExecuteExW`, глагол `runas`) **только для движка**; приложение от администратора не запускается. Вызов Windows — только в `crates/platform/src/windows/win32_ffi.rs`.
3. Отказ в запросе → «Ошибка»: «Нужны права администратора, чтобы включить обход». Из-за порядка действий VPN к этому моменту уже отключён.
4. После запуска до 5 секунд ждём: процесс жив И журнал `%LOCALAPPDATA%\SonicDPI\sonicdpi.log` появился или обновился (допуск 200 мс). Только потом «Включено».
5. Процесс умер или журнала нет → движок останавливается, «Ошибка»: «Обход не запустился. Перезагрузите компьютер и попробуйте снова».
6. Номер процесса берётся из ответа Windows; если его нет — процесс ищется по имени и пути `ochistkadpi.exe`. Чужие процессы не трогаются (проверка имени, пути, если он читается).

## Известные ограничения (честно)

- Процесс с повышенными правами обычное приложение завершить не может. Остановка делает отдельный запрос UAC (`C:\Windows\System32\taskkill.exe /PID <номер> /F`, только для процесса с именем `ochistkadpi.exe`). То есть при выключении обхода запрос прав может показаться снова. Это не проверено на Windows.
- Задание Windows «завершить при закрытии» к процессу с повышенными правами не применяется: при аварийном закрытии программы движок может остаться; при следующем запуске программа попробует завершить его по сохранённому номеру (с запросом прав).
- Журнал пишет сам движок (имя `sonicdpi.log` не меняется). Если запрос прав подтверждён другой учётной записью администратора, путь `%LOCALAPPDATA%` другой, и признак работы не появится: обход покажет ошибку.
- Старый журнал от прошлого запуска признаком не считается: проверяется время изменения файла.

## Тесты (фейки, Linux)

- Ядро: нет прав → один запрос; отказ → «Ошибка» с текстом выше; процесс умер → «Ошибка»; журнала нет → «Ошибка» и процесс остановлен; всё в порядке → «Включено».
- Платформа: запрос прав один раз с аргументами `run --profile youtube-discord`; без запроса при правах; отказ даёт метку отказа; номер не известен → поиск по имени и пути; чужой процесс не трогается; журнал старше запуска не считается.
- Компиляция слоя Windows проверена `cargo check --target x86_64-pc-windows-msvc`; сам вызов UAC в среде разработки не запускался.
