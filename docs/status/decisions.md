## 2026-11-19: Оформление, исправления по тесту на реальной Windows (look2)
- Мгновенный выбор: интерфейс рисует рамку и переключатель сразу, команда идёт в фоне через очередь (клики выполняются по порядку, интерфейс не ждёт). Ошибка: рамка снимается, показывается короткое сообщение бэкенда. Команда и раньше шла через `spawn_blocking`; задержку давали ожидание ответа и защита от повторных кликов. Диалоги подтверждения убраны (бэкенд по-прежнему требует `confirmed: true`, интерфейс шлёт его всегда).
- Курсоры не менялись из-за обновления через `rundll32 user32.dll,UpdatePerUserSystemParameters` (оно не перечитывает схему курсоров надёжно). Теперь `SystemParametersInfoW(SPI_SETCURSORS, 0, NULL, SPIF_UPDATEINIFILE | SPIF_SENDCHANGE)` через крейт `windows` в новом модуле `crates/platform/src/windows/win32_ffi.rs` (единственный unsafe в платформе кроме FFI ClamAV, у каждого вызова есть SAFETY). Файлы `.cur` проверены тестом (тип 2, горячие точки внутри кадра, DIB 32 бита, высота удвоена, маска AND, длины кадров). Пути в реестре абсолютные. Имя схемы пишется в значение по умолчанию ветки, `Scheme Source` = 1 (пользовательская схема). Возврат восстанавливает точные прежние значения и снова вызывает SPI_SETCURSORS.
- Анимация: «Занят» (Wait) и «Фоновая работа» (AppStarting) рисуются как `.ani` (RIFF ACON: LIST INFO, anih, rate, seq, LIST fram из 16 кадров-`.cur` 32/48/64): бегущая дуга второго цвета схемы по дорожке (Wait) и внутри бейджа стрелки (AppStarting), фигура и узор те же, что в схеме. 16 кадров и 3 размера на кадр — компромисс размера файла (~0,5 МБ) и плавности. Кадры всех ролей рисуются параллельно (`std::thread::scope`). В интерфейсе превью анимации: вращающееся кольцо на плитке при наведении.
- Обои: Windows хранит текущие обои в `TranscodedWallpaper` и перезаписывает его при смене, поэтому «прежний путь» не возвращал фон. Перед первой сменой текущий файл копируется в `%LOCALAPPDATA%\OCHISTKA\Backup\wallpaper-previous.<ext>` (без расширения — `.jpg`: Windows определяет формат по содержимому), в резерв пишется путь копии и прежние `WallpaperStyle`, `TileWallpaper`, `JPEGImportQuality`. Возврат выставляет их обратно, ставит копию; нет копии — обои Windows `%SystemRoot%\Web\Wallpaper\Windows\img0.jpg`; обоев не было — пустая строка. Если текущий фон уже наш из старой версии (резерва нет), «прежним» считаются обои Windows по умолчанию. Значение резерва переименовано в `PreviousWallpaperFile`, старый `PreviousWallpaper` игнорируется. Кнопка «Вернуть прежний фон» и повторный клик идут одним путём.
- Чёткость: Windows пережимает любые обои в JPEG с качеством 85. Перед сменой ставятся `JPEGImportQuality=100`, `WallpaperStyle=10` (Заполнить), `TileWallpaper=0` (прежние значения в резерве).
