- Звук реализован: кнопка «ЗВУК» переключает вкл/выкл, состояние в localStorage (`soundEnabled`, по умолчанию ВКЛ, с try/catch). Пасхалка `heehee.wav` подчиняется ему. Тесты FND-0020 обновлены, причина «в разработке» убрана. Статус: implemented (звук на реальной Windows не проверен).
- Панель: пункты — квадратные плитки 56 px (48 px при высоте окна ниже 600), радиус 12 px, иконки 32 px, подписи убраны (остались aria-label и title). Верхний край первого пункта = верхний край кнопок окна (Y=12), по REQUIREMENTS.md («верхняя линия обводки»); формулировка «центр» из задачи противоречит ей, выбран документ.
- Постер: `pop-art.png` из старого репозитория — именно этот файл (портрет в стиле поп-арт, 1024×1536), другого «Че Гевары» в старом репозитории нет. Использован как указано. Карточка 2:3, `object-fit: contain`, обрезки нет, масштаб пропорциональный.
- Единый контейнер: `main` в App.svelte (поля `--content-gutter`, макс. ширина 1480 px) общий для всех семи разделов; `scripts/layout-check.mjs` сверяет поля на 1179×803, 1920×1080, 2560×1440.
- Порядок разделов в sections.ts уже соответствовал требованию, не менялся.

## Оформление: системные обои, курсоры, цвета (shots-8)

- Плитка обоев ставит настоящие обои Windows (крейт `wallpaper`, только cfg(windows)). Прежние обои пишутся один раз в HKCU\Software\OCHISTKA\Backup\Appearance (PreviousWallpaper); выбранная плитка там же (AppliedWallpaper). Повторный клик по выбранной = возврат и снятие обводки; повторный возврат ничего не делает. Выбор читается из Windows, а не из localStorage.
- Оригиналы (набор Offline, около 105 МБ) в git не кладём. Приложение ищет `%LOCALAPPDATA%\OCHISTKA\Wallpapers\<id>.jpg|jpeg|png|bmp`. Если файла нет, интерфейс отдаёт превью (base64), ядро кладёт его в `Wallpapers\thumbs` и ставит обоями; уведомление только в stderr-журнале. Старого репозитория с набором в этой среде нет (`/home/user/ochistka-src/Assets` отсутствует), имена файлов оригиналов приняты как `<id галереи>.jpg`.
- Кнопка «Скачать оригиналы» видна, пока оригиналов нет; это заглушка: пишет причину в `Wallpapers\ORIGINALS.txt` и в журнал. План установщика: положить набор Offline в эту папку при установке (необязательный компонент), сервер раздачи выбрать позже.
- Сплошные плитки рисуются PNG 64x64 в `Wallpapers\solid`.
- Курсоры: `.cur` 32x32 (PNG внутри ICO, остриё стрелки как горячая точка, рисунок по центру) генерируются вручную без зависимостей и unsafe (`appearance_cursor.rs`); данные плитки (цвет, второй цвет, узор) приходят из таблицы интерфейса и проверяются ядром. Тот же контур рисует SVG плитки. Пишутся роли Arrow и IBeam, имя схемы и Scheme Source в HKCU\Control Panel\Cursors, резерв в HKCU\Software\OCHISTKA\Backup\Cursors, обновление через `%SystemRoot%\System32\rundll32.exe user32.dll,UpdatePerUserSystemParameters` (абсолютный путь). Остальные роли (Hand, Wait, ...) и анимация `.ani` пока planned: в таблице нет анимированных схем, анимацию в интерфейсе не имитируем.
- Цвета: клик ставит акцент (AppliedAccent), повторный клик возвращает прежний акцент из резерва; общий «Вернуть оформление Windows» остался.
- Клик по плитке и кнопки обоев выполняются без диалогов (клик и есть действие, всё обратимо); диалоги остались у переключателей прозрачности и тем. Сообщения «Готово», «применено», «не подключено» убраны, остались только ошибки Windows.
- Курсор приложения (CSS) удалён: курсор теперь системный.

## Фаза 1 правок v2 (оболочка)
- Картинки фона "из старой версии" в этой среде нет. Фоном раздела оставлен узор `pop-pattern.png`: один слой на всё поле раздела, `cover`, фокус по центру (без повторяющейся плитки и пустых полей). Непрозрачность 0.03: при более высокой контраст текста на синем и пурпурном падает ниже 4.5:1 в худшем пикселе.
- Кнопки окна 48 px (были 40), верхняя линия Y = 8 общая для логотипа, кнопок окна и первой плитки панели (сетка 8 px). Панель 112 px, поля страницы 24 px, радиус окна 12 px (тянет за собой RADIUS.lg = 12).
- Минимальный размер окна 900x544: семь плиток по 48 px помещаются без прокрутки вместе с развёрнутым блоком языка.
- Переключателя ОС в "Настройках" и "Бусте" в коде уже не было (он только в "Драйверах", по CLAUDE.md); добавлен тест.
- Тест "нет подсказки 'не подключено'" исключает файлы VPN (`lib/vpn.ts`, `lib/vpnNetwork.ts`, `Vpn*.svelte`): они переписываются в фазе 2.
- Строки-описания разделов (`lead`) переведены в i18n (`lead.*`); на экране берутся по `leadKey`.
- Подсказки при наведении (`title`) убраны с плиток панели и кнопки звука.
- Шаблон страницы: `PageShell.svelte` (заголовок, описание, слот вкладок, тело, подвал); в `App.svelte` обёртка тела страницы заменена им; остальные страницы не менялись.

Цвет «зелёный» первого экрана «Очистка» взят как `#b4ff00` (цвет «Вирусы»; `#f5ff00` у «Дисков» жёлтый). Задан в `VpnPage.svelte` правилом `.stage:has(.vpn)` (`--accent`, `--page-text`, фон), `tokens.ts` не менялся. Предложение для общей правки: сделать `SECTION_COLORS.vpn` зелёным (тогда правило не нужно; плитка панели останется розовой, пока не обновят Navigation).
- Узор остаётся общим слоем оболочки (cover, центр), главного объекта на нём нет, обрезки нет.
- Заголовок, описание и вкладки рисует только PageShell (в App). Названия вкладок остаются из `sections.ts` («VPN», «Дополнительно», «Сеть», «Соединения»): файл общий; переименование в «Подписка и импорт»/«Маршруты и исключения» — предложение владельцу раздела sections.
- Заглушки без текста «не подключено»: переключатель подключения, режим TUN, переключатели Zapret и Xbox DNS отключены (`disabled`), диалог и причины убраны; остаётся краткая подпись «Нужен драйвер TUN». Импорт валидной https-ссылки пишет «Ссылка проверена» (загрузки нет).
- «Соединения»: галочек и флажков не было; добавлен выбор строки одной обводкой, строка 32 px, счётчик внутри карточки.
- Строки страницы VPN переведены в `vpn.*` (RU/EN); причины из `lib/vpn.ts` остаются русскими.
- Общая рабочая папка у параллельных агентов: `git stash` использовать нельзя (я случайно стэшнул чужие правки и вернул их из стэша; i18n JSON слиты по ключам).

## Фаза 2: «Диски» (блоки 4 и 6)
- PageShell уже обёртывает страницы в App.svelte; страница «Диски» теперь рисует только единый заголовок «ДИСКИ / <подраздел>» (h2) и своё содержимое.
- Пасхалка: `pop-art.png` на «Глубокой очистке» (кнопка 3:4, cover, фокус 50% 55%: лицо не режется), клик играет `heehee.wav` через `playHeehee` (учитывает переключатель звука), анимация масштаба 260 мс, при `prefers-reduced-motion` без анимации.
- Общая правка DTO: `DiskStatus.model?: string` (необязательное; Rust `model: Option<String>`, `skip_serializing_if`). Сгенерированный `DiskStatus.ts` обновлён; в `api.test.ts` регулярка `generatedKeys` понимает `name?:`.
- Модель: `ochistka_core::disk_model` (`short_model`: убирает служебные слова и серийные токены, максимум 3 слова, «KINGSTON» -> «Kingston»), связь буква -> модель через WMI Win32_DiskDriveToDiskPartition и Win32_LogicalDiskToPartition (`platform/windows/disk_models.rs`). Не проверено на Windows. Неизвестная модель: «Модель неизвестна», без подсказки.
- Тип «неизвестен» рисуется как HDD-иконка, подпись «Тип неизвестен».
- Названия категорий очистки в EN переводятся по id на фронтенде (`localizeCategoryTitle`); тексты ошибок бэкенда и причины в манифесте карантина остаются русскими.
- Файл `Cargo clippy --workspace` на момент работы падает на чужом `filetime_now` (platform/windows/programs.rs, dead code); к дискам не относится.
