# VPN: статус (Windows 10/11 x64)

Дата: 2026-11-19. Поведение 0.5.5 для сверки: `docs/status/vpn-0.5.5-behaviour.md`. Скриншоты: `docs/status/vpn-fix/`.

## Почему раньше «ничего не происходило»
Раздел был заглушкой: кнопка «Подключить» возвращала фиксированный текст, импорт только проверял вид ссылки, Rust-команд для VPN не было вовсе. Сеть и процессы в интерфейсе не вызывались.

## Что сделано (implemented, не проверено на Windows)
- Импорт в Rust: ссылка `https://` (скачивание без участия браузера), вставленный список ссылок, файл. Форматы: `vless`, `vmess`, `trojan`, `ss`, `hysteria2`, `tuic`; список ссылок обычный или base64; JSON sing-box. Не поддерживаются Clash YAML, Xray JSON, транспорты xhttp/kcp/quic, SS с плагином: такие записи пропускаются с причиной.
- Список серверов: имя, страна (флаг-эмодзи, код в имени или название страны), протокол, задержка TCP.
- Подключение: ядро sing-box (как в 0.5.5, версия 1.14.4) запускается дочерним процессом, режим «Системный прокси»: `mixed` 127.0.0.1:порт, прокси Windows выставляет приложение с копией прежних значений (`HKCU\Software\OCHISTKA\Backup\VpnProxy`). Откат: при отключении, при выходе из приложения и при следующем запуске после аварии (файл `core.pid` + копия реестра).
- Подвкладка «Маршруты и исключения»: домены и приложения напрямую/через VPN, наборы.
- Ядро не хранится в git: `tools\vpn-core\fetch.ps1` (или `fetch.sh`) скачивает выпуск sing-box с проверкой SHA-256 в `apps/desktop/src-tauri/resources/vpn-core/`. Без ядра интерфейс показывает причину и команду.

## Не сделано / ограничения
- TUN (весь компьютер): нужны права администратора и драйвер; в интерфейсе выключен.
- Xray для XHTTP/REALITY-профилей из 0.5.5 не подключён: такие записи (xhttp) пропускаются.
- Профили хранятся обычным JSON в `%LOCALAPPDATA%\OCHISTKA\vpn` (в 0.5.5 был DPAPI; вернём, когда появится безопасная обёртка).
- Zapret и Xbox DNS по-прежнему заглушки; GoodbyeDPI скрыт.
- Проверки на реальной Windows не было: запуск ядра, запись реестра и обновление прокси WinINet надо проверить руками.
