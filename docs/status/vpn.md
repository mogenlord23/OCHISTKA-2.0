# VPN: статус (Windows 10/11 x64)

Дата: 2026-11-18. Раздел 7 `docs/PLAN.md`, пункты 7.1 и 7.2.

- **Готово (implemented, не проверено на Windows):** ссылка подписки с проверкой только `https://`; разбор текста подписки (`vless`, `vmess`, `trojan`, `ss`, имя из фрагмента, нераспознанные строки считаются); переключатель подключения с таймером ЧЧ:ММ:СС; блок «Дополнительно» с переключателями Zapret и Xbox DNS (статус «выключено»). GoodbyeDPI не показывается.
- **Заглушка: подключение.** Нажатие возвращает «Подключение не подключено: нужен драйвер TUN» и ничего не меняет. Режим TUN выключен с причиной.
- **Заглушка: импорт.** После проверки ссылки показывается «Загрузка подписки пока не подключена». Сетевой загрузки нет.
- **Заглушка: Zapret и Xbox DNS.** Включение возвращает «Изменение сети пока не подключено». Системные настройки не меняются. Перед будущей реализацией нужен запрос подтверждения в интерфейсе.
- **Нужна Windows:** TUN-драйвер, переключение DNS, запуск Zapret, проверка переключателя на реальной системе. Текущие заглушки не трогают систему, поэтому тесты и запуск приложения безопасны.
- **Ограничения разбора:** base64-тело подписки не декодируется. Имя из `vmess` берётся из фрагмента, а не из поля `ps`.
