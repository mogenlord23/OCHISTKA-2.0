## Что подтверждено на настоящем Windows (по журналу первого запуска)

- SHA-256 архива SonicDPI v0.2.2 (`ec1e9f32…991fc0`) и файла `ochistkadpi.exe` (`3d645102…5351`) совпали.
- Служба `OchistkaBypass` ставится скриптом `bypass-service.ps1` (тем же, что в установщике): тип запуска «вручную» (`DEMAND_START`), учётная запись `LocalSystem`.
- В правах службы есть запись для Authenticated Users `(A;;LCRPWPLO;;;AU)` (запрос состояния, запуск, остановка).
- Запуск: через 5 секунд `RUNNING`, процесс `ochistkadpi` работает, служба драйвера `WinDivert` запущена.
- Остановка: `STOPPED` достигнуто, процесса нет, `WinDivert` после остановки не установлен (служба-оболочка убрала драйвер).
- Удаление: служба удалена (`NOT_INSTALLED`).
- Логи — в артефакте запуска (`windows-service-check-logs`).

## Не проверено

- Запуск и остановка службы обычным пользователем без прав администратора (CI проверяет только запись в правах, запуск идёт от администратора раннера).
- Установщик NSIS целиком (запрос прав один раз, хуки установки и удаления, режим «для всех пользователей»).
- Defender и другие защиты на машине пользователя.
- Реальный обход у провайдера и голос Discord; список сайтов службе не передаётся.
- macOS и Linux (отдельно, позже).
