# Этап 5Б.1: импорт VPN-подписок

Проверено в Cloud (Linux, вымышленные подписки). Реальная загрузка по HTTPS делается только на Windows
(адаптер `crates/platform/src/vpn.rs`, SChannel): здесь не проверялась.

## Где импорт мог отказать (найдено по коду)
1. Ссылка: только `https://`, обёртки `v2raytun://`, `happ://` и др. раскрываются; зашифрованные `happ://crypt…` раскрыть нельзя.
2. Скачивание: два имени клиента подряд (v2rayN, v2rayTun), до 5 переходов только на https, лимит 5 МБ, таймаут 25 с.
3. Ответ: 401/403/404/410/429/5xx переводятся в короткие русские сообщения (без кода и ссылки).
4. Формат: JSON, список ссылок, base64. **Clash YAML и Xray JSON раньше не читались**: давали «нет поддерживаемых серверов».
5. Разбор: транспорты `xhttp`, `splithttp`, `kcp`, `quic` и VLESS с `encryption≠none` ядро sing-box не поддерживает, такие записи пропускаются.
6. Интерфейс: показывает итог и причины пропуска.

## Что исправлено
- Xray JSON (vless, vmess, trojan, shadowsocks; tcp/ws/grpc/httpupgrade; tls/reality) преобразуется в sing-box (`vpn/xray.rs`).
- Ошибки разделены: пустой ответ; формат Clash; формат не распознан; серверы найдены, но все пропущены (причины сгруппированы «×N», без ссылок и ключей).
- Итог импорта: «Импорт завершён: серверов N. Часть записей пропущена (M): причины».
- `tools/vpn-diagnose.ps1`: безопасная сводка по ссылке подписки (без ссылки и ключей).

## Не сделано
- Clash YAML: нужен разбор YAML (отдельный небольшой этап).
- Транспорт xhttp: его нет в sing-box, обойти нельзя.

## 5Б.2: проверка на структуре настоящей подписки (данные диагностики Windows)
Настоящий ответ: Xray JSON, 10 конфигов, 9 VLESS (gRPC 6, TCP 3), 1 Hysteria, служебные freedom и blackhole.
Тест `realistic_ten_config_subscription…` (вымышленные данные той же структуры): 10 серверов, служебные
исходящие не попадают в список, gRPC+REALITY и TCP+TLS преобразуются в sing-box, Hysteria (версия 2, пароль из
`hysteriaSettings.auth`) становится `hysteria2`. Форма Hysteria предположена по формату Xray и не проверена на
настоящих данных: при отличии запись будет пропущена с понятной причиной.
