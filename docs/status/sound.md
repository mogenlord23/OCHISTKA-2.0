# Звук: образец и наш синтез (круг 5, T4)

Образец владельца `tap-ref.mp3` (лицензия неизвестна) используется только как справка, в приложение не включён.

| Показатель | Образец | click | switch |
|---|---|---|---|
| Длительность звука | ~50 мс после 22 мс тишины (файл 1 с) | 70 мс | 76 мс |
| Время до пика | ~10 мс от начала звука | 6 мс | 8 мс |
| Спад до -20 дБ | ~26 мс от пика | ~28 мс | ~30 мс |
| Центроид | 568 Гц | 557 Гц | 468 Гц |
| Энергия 500-1000 Гц | 98,2 % | 98,9 % | 1,4 % (основная 200-500: 98,3 %) |
| Энергия выше 2 кГц | 0 % | 0 % | 0 % |
| Пик | -2 dBFS | -18 dBFS | -18 dBFS |
| Размер файла | mp3 | 3,1 КБ | 3,4 КБ |

Воспроизведение: файлы декодируются заранее (`preloadSounds`), одно действие это один `start()`; повторный звук в течение 60 мс глушится; всё подчинено переключателю «Звук». На слух не проверялось (нет звукового устройства).
