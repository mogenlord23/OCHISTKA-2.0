# Нагрузочные проверки VPN (этап 18)

Это тесты на фейках (без ядра и без Windows): они проверяют логику сервиса, а не реальную скорость сети.

| Проверка | Тест | Результат (этот компьютер, Linux) |
|---|---|---|
| 500 переключений «Весь компьютер» ↔ «Только сайты» подряд при включённом VPN | `five_hundred_switches_in_a_row_leave_no_state_behind` | всего ≈ 0,29 с, самое долгое ≈ 7 мс; после каждого прохода флаг смены снят, затвор свободен, состояние «включено»; в конце всё выключается, конфигурация с ключами стёрта, право на сеть свободно |
| 2 000 добавлений сайтов по одному | `two_thousand_additions_stay_correct_and_fast` | всего ≈ 13 с (≈ 6,6 мс на добавление при списке до 2 000), повторы не растут, файл < 1 МБ, удаление работает |

Замечания:
- Время добавления растёт с размером списка (каждый раз список читается и проверяется заново). До 10 000 сайтов одно добавление остаётся в пределах долей секунды; массовая вставка списком выполняется за один проход.
- Реальные переключения на Windows занимают время остановки и запуска ядра (секунды); это проверяет владелец.
- Состояния при переключении: выключено, переключаем, включено, ошибка. Тесты: `every_area_transition_ends_in_a_stable_state`, `an_error_in_the_middle_of_a_switch_returns_to_the_last_working_area`, `while_switching_the_screen_sees_switching_and_a_second_press_is_ignored`.
