# Фаза 1 (оболочка): какие плагины запускались и что дали

Снимки: `docs/status/review-v2/phase1-*.png` (Linux, Chromium, вызовы Tauri подменены). Проверено только на Linux.

## ui-design-review:review (скилл ui-review)

Запущен, UXKIN MCP не подключён (нужна авторизация), сравнения с реальными продуктами нет. Смотрел снимки 900x544, 1179x803, 1920x1080, свёрнутый блок языка. Находки:

- Нужно исправить: кнопки окна стояли у правого края окна, а не у края контейнера содержимого (на 1920 разрыв 150 px). Исправлено: правое поле строки окна равно левому (`--content-gutter`).
- Нужно исправить: служебный текст 9-10 px (подпись автора, подписи блока ЗВУК/язык, нижняя строка). Исправлено: 11 px (`--text-caption`).
- Нужно исправить: зона нажатия ручки блока языка 24 px. Исправлено: невидимая зона 48x40 (`::after`).
- Желательно (не сделано, фаза 2): VPN-страница рисует свой заголовок, описание и вкладки второй раз внутри PageShell; уйдёт при переносе на PageShell.
- Желательно (не сделано): иконки панели без подписей и без подсказок (решение ADR 0010 п.3); имя раздела читают только экранные дикторы.

## ui-design-review:ui-polish

Применил исправления "нужно исправить" выше, а также: минимальная высота окна 520 -> 544 (11 px шрифт блока языка добавил 2 px, 544 кратно 8), на 900x544 панель без прокрутки (измерено). Контроль рендером: тесты + Playwright, прокрутки панели нет, горизонтальной прокрутки нет.

## design:accessibility-review (WCAG 2.1 AA, контраст)

- Текст страницы на цвете раздела: >= 4.5:1 для всех 7 разделов, в том числе при самом тёмном пикселе узора (тест `BACKDROP`; из-за пурпурного и синего непрозрачность узора снижена с 0.07 до 0.03).
- Тексты панели: ink на кнопке 18.1, muted на кнопке 5.5, muted на панели 5.8, значки 19.7.
- Найдено и исправлено (1.4.11): граница кнопок блока языка 1.37:1 с панелью; теперь `#767676` (около 4:1), нажатая кнопка обведена `--ink`.
- Остаётся: общая граница `SHELL.buttonBorder` (#2a2a2a) на страницах разделов слабая (1.37:1); правится при переносе страниц в фазе 2.
- Клавиатура: двойное кольцо фокуса есть (focus-ring.test); все значки с `aria-label`. Экранным диктором не проверялось.

## VPN (фаза 2, блок 3)
Навыки ui-design-review:review, ui-polish и design:accessibility-review как плагины НЕ запускались (UXKIN MCP не авторизован). Фактически: ручной разбор снимков 900x544, 1179x803, 2560x1440 (docs/status/review-v2/vpn-*.png).
- Исправлено: счётчик соединений стоял вне карточки и сдвигал начало контента; выбор строки только обводкой 2 px (не цветом); отступы и высоты кратны 8; текст 11 px минимум; зоны нажатия кнопок 40-48 px.
- Контраст: чёрный текст на #b4ff00 около 17:1; подписи ink на чёрных карточках > 12:1; muted на карточке >= 4.5:1 (как в оболочке).
- Клавиатура: строки соединений в Tab-порядке, Enter/Пробел выбирают, фокус-кольцо через outline. Экранным диктором не проверялось.
