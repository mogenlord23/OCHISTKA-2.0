# Фаза 1 (оболочка): какие плагины запускались и что дали

Снимки: `docs/status/review-v2/phase1-*.png` (Linux, Chromium, вызовы Tauri подменены). Проверено только на Linux.

## ui-design-review:review (скилл ui-review)

Запущен, UXKIN MCP не подключён (нужна авторизация), сравнения с реальными продуктами нет. Смотрел снимки 900x544, 1179x803, 1920x1080, свёрнутый блок языка. Находки:

- Нужно исправить: кнопки окна стояли у правого края окна, а не у края контейнера содержимого (на 1920 разрыв 150 px). Исправлено: правое поле строки окна равно левому (`--content-gutter`).
- Нужно исправить: служебный текст 9-10 px (подпись автора, подписи блока ЗВУК/язык, нижняя строка). Исправлено: 11 px (`--text-caption`).
- Нужно исправить: зона нажатия ручки блока языка 24 px. Исправлено: невидимая зона 48x40 (`::after`).
- Желательно (не сделано, фаза 2): VPN-страница рисует свой заголовок, описание и вкладки второй раз внутри PageShell; уйдёт при переносе на PageShell.
- Желательно (не сделано): иконки панели без подписей и без подсказок (решение ADR 0010 п.3); имя раздела читают только экранные дикторы.

## ui-design-review:ui-polish

Применил исправления "нужно исправить" выше, а также: минимальная высота окна 520 -> 544 (11 px шрифт блока языка добавил 2 px, 544 кратно 8), на 900x544 панель без прокрутки (измерено). Контроль рендером: тесты + Playwright, прокрутки панели нет, горизонтальной прокрутки нет.

## design:accessibility-review (WCAG 2.1 AA, контраст)

- Текст страницы на цвете раздела: >= 4.5:1 для всех 7 разделов, в том числе при самом тёмном пикселе узора (тест `BACKDROP`; из-за пурпурного и синего непрозрачность узора снижена с 0.07 до 0.03).
- Тексты панели: ink на кнопке 18.1, muted на кнопке 5.5, muted на панели 5.8, значки 19.7.
- Найдено и исправлено (1.4.11): граница кнопок блока языка 1.37:1 с панелью; теперь `#767676` (около 4:1), нажатая кнопка обведена `--ink`.
- Остаётся: общая граница `SHELL.buttonBorder` (#2a2a2a) на страницах разделов слабая (1.37:1); правится при переносе страниц в фазе 2.
- Клавиатура: двойное кольцо фокуса есть (focus-ring.test); все значки с `aria-label`. Экранным диктором не проверялось.

## VPN (фаза 2, блок 3)

Навыки ui-design-review:review, ui-polish и design:accessibility-review как плагины НЕ запускались (UXKIN MCP не авторизован). Фактически: ручной разбор снимков 900x544, 1179x803, 2560x1440 (docs/status/review-v2/vpn-*.png).

- Исправлено: счётчик соединений стоял вне карточки и сдвигал начало контента; выбор строки только обводкой 2 px (не цветом); отступы и высоты кратны 8; текст 11 px минимум; зоны нажатия кнопок 40-48 px.
- Контраст: чёрный текст на #b4ff00 около 17:1; подписи ink на чёрных карточках > 12:1; muted на карточке >= 4.5:1 (как в оболочке).
- Клавиатура: строки соединений в Tab-порядке, Enter/Пробел выбирают, фокус-кольцо через outline. Экранным диктором не проверялось.

## Процессы, Программы, Вирусы (фаза 2, блок 8)

Плагины ui-design-review:review, ui-polish, design:accessibility-review, rust-cli-skills:rust-processes и rust-errors как навыки НЕ запускались (UXKIN MCP не авторизован; скиллы не вызывались, чтобы не тратить токены, по CLAUDE.md). Фактически: ручной разбор снимков 1179x803, 2560x1440, 980x640 (docs/status/review-v2/proc-*.png, скрипт proc-verify.mjs).

- Причины пустых значков (диагноз): (1) у большинства Win32-программ нет `DisplayIcon`, у Store-пакетов значка не было вовсе; (2) неудача кэшировалась и рисовалась пустой буквой; (3) ответ платформы мог прийти с префиксом `data:` (теперь убирается). Путь data URL проверен тестом с настоящим PNG (AppIcon.test.ts) и Rust-тестами.
- Исправлено: значок по id программы (DisplayIcon, затем логотип из AppxManifest.xml только чтением, затем основной exe в папке установки); заглушка — цветной квадрат с глифом окна; список виртуализирован (VirtualList: transform, обновление раз в кадр, высота задаётся CSS); поле поиска: цвет подсказки.
- Заголовок на одной позиции во всех трёх разделах (72 px сверху, одинаково), горизонтальной прокрутки нет.
- Rust (ручная проверка по темам rust-errors и rust-processes): чтение файлов с лимитом размера, без `..`, ошибки возвращают причину и кэшируются как «нет значка», а не ошибка интерфейса; запуск деинсталлятора и автозагрузка не менялись (подтверждение и прежнее значение сохраняются).
- Не проверено на реальной Windows: чтение манифеста и выбор exe на настоящих пакетах WindowsApps; `DisplayIcon` с `%переменными%` по-прежнему не поддерживается (заглушка). Экранным диктором не проверялось.

## Фаза 2, блок 5 «Оформление»

Снимки: `docs/status/review-v2/appearance-*.png` (900x544, 1179x803, 2560x1440; Linux, Chromium, Tauri подменён; скрипт `apps/desktop/scripts/appearance-check.mjs`, все проверки пройдены).

- superpowers:writing-plans: короткий список правок держал в голове по ТЗ (пункты 1-9), отдельный файл плана не создавал. superpowers:test-driven-development: тесты на новое поведение написаны до кода (красные), затем зелёные.
- ui-design-review:review / ui-polish, design:accessibility-review, ui-design-review:compare: отдельными вызовами скиллов НЕ запускались (UXKIN MCP требует авторизации). Вместо них осмотр снимков вручную и замеры в Chromium. Находки и исправления: боковые поля сетки на 2560 (были, исправлено `1fr`), прямоугольные и смещённые плитки (квадрат 1:1, cover по центру), линия при наведении (убрана тень, оставлен transform), обводка выбора внутри плитки с тем же скруглением. Сравнение с ref-12/ref-14 (owner-3): тёмные плитки-чипы, цветная сетка и расположение заголовка совпадают; в ref-14 цвета остались прямоугольными 3:2.
- Доступность: у плиток `aria-label` и `aria-pressed`, у кисти `aria-hidden`; кнопка «Вернуть как было» неактивна через `aria-disabled`; анимация курсора выключается при reduced-motion. Контраст обводки на белой плитке держится тонкой тёмной линией внутри рамки. Экранным диктором не проверялось.
- anthropic-skills:frontend-design: такого скилла в списке этой сессии нет. Кисти нарисованы вручную как два SVG (вариант A выбран, см. ADR 0011).

## Диски (фаза 2, блоки 4 и 6)

Плагины ui-design-review:review, ui-polish, ui-compare и design:accessibility-review НЕ запускались (UXKIN MCP не авторизован; по CLAUDE.md тяжёлые навыки не вызывались). Фактически: ручной разбор снимков 900x544, 1179x803, 2560x1440 (docs/status/review-v2/disks-*.png, скрипт Playwright на порту 1462 с подменой invoke) и сравнение с docs/design/reference/owner-3 (плитки: крупный значок слева, буква, строки объёма).

## Фаза 2, блок 7: «Компьютер» (Linux, Chromium, вызовы Tauri подменены; на Windows не проверялось)
