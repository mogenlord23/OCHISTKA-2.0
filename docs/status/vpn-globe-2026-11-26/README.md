# Планета VPN и палитра, 26 ноября 2026

Рабочая копия на ПК владельца — `B:\Desktop\ochistka-scan-round31`, ветка `codex/viruses-computer-scan`. Процесс запущенного приложения и команда Vite указывали на эту копию. В начале проверки HEAD был `d5d5af8`. Текущие локальные исправления импорта, выбора группы, опроса и экрана соединений сохранены в выпуске. Коммит оформления — `854ce76`.

## Изменения

- Геометрию и скорость вращения сверили с `023d8be`. В `d5d5af8` шаг выборки суши вырос с 4 до 8 по обеим осям, а задержка вращения составила 80 мс плюс ожидание кадра. В локальном варианте перед проверкой обычный вид представлял собой растянутый ролик 512×256 с частотой 30 кадров/с.
- Вращение использует исходные координаты всей карты, один буфер вершин WebGL и один вызов рисования точек за кадр. Размер холста соответствует физическим пикселям. Для страны и группы используется интерактивная карта с плавным приближением. При недоступности WebGL работает Canvas2D. Ресурсы освобождаются при уходе с экрана.
- Во время разработки на GTX 1060 измерили 240 кадров/с без ограничения и 60 после изменения расписания. Скорость поворота составляет 0,16 радиана/с. Окно и документ сообщают о скрытии независимо. Опрос состояния и измерение задержки учитывают видимость.
- Проверка с отключённым рендерером показала 10,86% CPU на открытом VPN. При остановке смены декоративных букв в поле подписки и работающей планете получилось 3,38%. Дополнительное отключение опроса в этом коротком интервале дало 4,55%. Время появления заменённого символа сокращено до 210 мс. Это изменение касается только маски ввода.
- Курсоры и цвета используют одну CSS-сетку и обводку. Для всех 69 прежних образцов сохранены идентификаторы и точные HEX, добавлены семь насыщенных цветов. Windows хранит выбранный HEX.

## Измерения Windows 11

Tauri dev, окно 900×760, монитор 1920×1080, один ПК. Каждый замер длится шесть секунд после паузы. CPU нормирован на все восемь логических процессоров. Память — сумма рабочих наборов приложения и его дочерних WebView2 в МиБ, включая общие страницы. Исходное и финальное измерения проведены в разных запусках.

- **PASS, Windows 11 / WebView2.** В минимальном и развёрнутом окнах реальные плитки обеих сеток соответственно 144×105 и 140×105. Три изменения цвета проверены по значениям Windows DWM. Холодный запуск прочитал последний выбранный цвет. После теста исходный акцент был восстановлен и сверен с DWM.
