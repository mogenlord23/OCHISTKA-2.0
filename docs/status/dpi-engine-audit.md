## 4. Итоговый выбор

**Выбран SonicDPI (by-sonic/sonicdpi).**

Почему:
- Единственный из шести, у кого в README подтверждены все три ОС и голос Discord по UDP одновременно; MIT/Apache-2.0 совместимы с любой будущей лицензией OCHISTKA.
- Один движок на всех ОС вместо двух разных (winws2 + nfqws2) — меньше платформенного кода в `crates/platform`.
- Написан на Rust: может подключаться как внешний процесс за `DesyncAdapter` (как сейчас winws2), без смены архитектуры.

Условия и риски (не подтверждены):
- Проект новый; его работа у провайдера владельца неизвестна; README сам предупреждает, что рабочий профиль зависит от DPI провайдера.
- Для Linux заявлено ядро ≥ 6.17, для macOS нужен root; поддержка macOS и Linux в README частично «в работе».
- Windows-путь у OCHISTKA уже есть (winws2); **не удалять**. Предлагаемый порядок: сначала проверить SonicDPI на Windows владельцем рядом со winws2, и только после его подтверждения подключать вторым адаптером.

Запасной вариант: оставить winws2 на Windows (подтверждённо рабочий путь кода) и вернуться к выбору для Linux/macOS отдельно.
