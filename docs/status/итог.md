# OCHISTKA 2.0 — итог этапа (2026-11-18)

Проверено на Linux: `cargo test --workspace`, clippy с `-D warnings`, `cargo fmt --check`, `npm test` (196 тестов), `svelte-check` (0/0). На Windows ничего не запускалось.

## Готово (код и тесты)

- Окно без рамки, панель разделов (Вирусы первым, VPN открывается), RU/ENG для оболочки.
- Компьютер: CPU и RAM раз в секунду, графики за 90 секунд, плитки, тип диска SSD/HDD, имя и версия ОС.
- Диски: глубокая очистка через карантин (манифест, восстановление, окончательное удаление по токену), read-only страницы.
- Процессы: список, поиск, завершение только с подтверждением и проверкой PID.
- Программы: установленные из реестра и автозагрузка (только чтение).
- Вирусы: слой проверки (инвентаризация, эвристика с причинами, итоговая оценка), карантин находок, журнал.
- VPN: импорт https-подписки (разбор ссылок), таймер, стаб подключения, переключатели Zapret и Xbox DNS (стабы).
- Оформление: обои, курсоры, цвета — выбор сохраняется.

## Заглушки (с причиной в интерфейсе)

- Движок libclamav: не собран (нет доступа к исходникам из среды). См. `docs/status/clamav-build.md`.
- ИИ-слой: заглушка без оценки. Обновление сигнатур — из папки, freshclam не подключён.
- Подключение VPN и режим TUN; изменение сети (Zapret, DNS); применение обоев и курсоров к Windows.
- Служб, Store, Настройки, Boost, Драйверы (список), GPU и материнская плата.
- Перевод: переведена только оболочка, содержимое разделов на русском.

5. Процессы: реальные значения CPU, завершение процесса.
