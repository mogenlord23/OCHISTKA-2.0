# Дизайн v2: палитра разделов, токены и шрифты по брифу

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Привести цвета разделов, шрифты и базовые токены к дизайн-брифу `docs/design/brief.md`, не дожидаясь скриншотов.

**Architecture:** Цвета и шрифты лежат в одном модуле `src/lib/tokens.ts`; `sections.ts` берёт цвет раздела оттуда. Компоненты читают CSS-переменные, которые `App.svelte` выставляет из токенов.

**Tech Stack:** Svelte 5, TypeScript, Vitest.

**Spec:** `docs/design/brief.md` (бриф по скриншотам старой версии 0.5.5).

## Global Constraints

- Порядок и названия семи разделов не меняем: Вирусы, VPN, Процессы, Программы, Диски, Компьютер, Оформление (в навигации порядок VPN первым — решение владельца).
- Фирменная строка внизу: «ЛОКАЛЬНО. ПОД ТВОИМ КОНТРОЛЕМ.».
- Цвета из брифа — ориентиры; точные HEX снимаются пипеткой со скриншотов (этап после получения эталона).
- Чужие иллюстрации (портреты Warhol) не копируем.
- Conventional Commits, маленькие коммиты.

## Review Focus

1. Цвет текста на цветном фоне раздела: тест Task 2 проверяет порог 4.5:1 для каждого раздела. Расчёт: чёрный текст на фиолетовом «Компьютере» (#cf00ff) — 4.86:1, на розовом VPN (#ff009d) — 5.47:1; белый на обоих ниже порога. Поэтому текст страницы чёрный, `textOn` выбирает его автоматически.
2. `prefers-reduced-motion`: сканирование стоит на месте, а состояние меняется текстом. Тест: стиль анимации отключён в media-запросе (Task 3, файл VirusesPage.svelte уже содержит правило — тест проверяет наличие правила).
3. Шрифт не найден на машине (Arial Black отсутствует): заголовки падают на системный жирный, без ошибки и без сдвига макета — проверяется стеком `font-family`.
