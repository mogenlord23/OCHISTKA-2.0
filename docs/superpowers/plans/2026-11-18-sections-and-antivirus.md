# Семь разделов и раздел «Вирусы» (ClamAV, эвристика, анимация)

> **For agentic workers:** выполняется в этой сессии по TDD; каждая задача — отдельный коммит.

**Цель:** перестроить навигацию по семи разделам с подразделами; перенести сведения о системе в «Компьютер»; сделать раздел «Вирусы» с проверкой через ClamAV, эвристической оценкой и анимацией проверки.

**Вне этапа:** карантин и удаление (кнопка выключена), ONNX-модель, раздел VPN (только каркас), Программы/Диски/Оформление (только каркас), Очистка/Оптимизация/Сеть/Виджеты/Настройки (не распределены).

## Задачи

1. **Ядро: разбор вывода ClamAV.** `parse_clamscan_output` в `crates/ochistka-core/src/scan.rs`: находки «путь: сигнатура FOUND», сводка «Infected files: N». Тесты на фикстурах вывода.
2. **Ядро: эвристика.** `score_suspicion(file: &FileFacts) -> Suspicion` с причинами. Тесты: двойное расширение, исполняемый файл в загрузках, обычный документ.
3. **Порт сканера.** Трейт `VirusScanPort` в ядре, `ScanRequest`/`ScanReport` (DTO, camelCase).
4. **Платформа: адаптер ClamAV.** `crates/platform/src/windows/clamav.rs`: поиск `clamscan.exe` в папке установки, сборка аргументов, запуск по абсолютному пути. Тесты: путь собирается, аргументы без PATH, отсутствие движка даёт `Unsupported` с причиной.
5. **Tauri-команды.** `scan_start`, `clamav_status` в `apps/desktop/src-tauri`. Тесты на чистой логике команд с фейковым портом.
6. **Интерфейс: навигация.** Правая панель, семь разделов со статусом, подразделы — вкладки. Тест: семь разделов в порядке, подразделы на месте.
7. **Интерфейс: «Вирусы».** Подразделы Проверка / Находки / Журнал. Анимация запуска (полоса сканирования), цвета палитры, `prefers-reduced-motion` отключает движение. Тесты компонентов.
8. **Интерфейс: «Компьютер».** Сведения CPU/RAM/диски переехали сюда, подразделы Комплектующие, Настройки, Boost, Драйверы (каркас).
9. **Документы.** `platform-status.md` и README под новую структуру.
