# OCHISTKA 2.0: дизайн-бриф по скриншотам старой версии 0.5.5

Эталон: 12 скриншотов в папке `B:\Desktop\ылкуфт`. Новая версия делает тот же внешний вид на современном движке (Tauri 2 + Svelte 5). Копируем композицию, цвета, типографику и характер, а не старый код.

## Структура окна

- Окно без системной рамки. Справа в верхней части — кнопки «свернуть», «развернуть», «закрыть».
- Слева — логотип «OCHISTKA» крупным жирным шрифтом, под ним мелко «Create: Slava Lavs».
- Правая боковая панель (шириной около 110 px): чёрная, иконки в контуре, подписи под ними. Активный пункт — заливка цветом раздела, скруглённый прямоугольник.
- Порядок разделов: Вирусы, VPN, Процессы, Программы, Диски, Компьютер, Оформление.
- Внизу справа: кнопка «ЗВУК ВКЛ», переключатель RU / ENG, версия.
- Внизу слева всегда строка «ЛОКАЛЬНО. ПОД ТВОИМ КОНТРОЛЕМ.» — фирменная фраза, оставляем.

## Раздел: цвет фона

Каждый раздел имеет свой полноэкранный цвет фона. Это главный узнаваемый элемент.

| Раздел     | Фон (ориентир по скриншоту)                                         |
| ---------- | ------------------------------------------------------------------- |
| VPN        | ярко-розовый                                                        |
| Оформление | коралловый красный                                                  |
| Диски      | жёлто-лаймовый                                                      |
| Компьютер  | пурпурный                                                           |
| Процессы   | синий                                                               |
| Программы  | оранжевый                                                           |
| Вирусы     | скриншота нет, подобрать в той же палитре (уточнить у пользователя) |

Точные HEX-значения снимаются с скриншотов инструментом пипетки на этапе токенов, а не угадываются.

## Общие элементы

- **Фон:** цветной, с едва заметным рисунком pop-art (мелкие силуэты предметов). Рисунок почти не виден, он создаёт фактуру.
- **Карточки:** почти чёрные (около #111), скругление 10–14 px, без теней или с очень мягкой.
- **Заголовок раздела:** очень жирный, широкий, капсом (например «КОМПЬЮТЕР», «ДИСКИ / ПРОСТРАНСТВО»). Под ним короткая строка описания, жирным мелким шрифтом.
- **Подразделы:** чёрные скруглённые кнопки-вкладки. Активная подсвечивается цветом раздела.
- **Кнопки:** чёрные, скруглённые, белый текст. Выключенное состояние — приглушённое.
- **Поля поиска и ввода:** тёмные, широкие, с подписью капсом над полем.
- **Переключатели:** большие, цветом раздела, с белым кругом.
- **Списки:** таблица с чёрным заголовком, строки разделены тонкой линией, иконки приложений слева.
- **Плитки комплектующих:** карточка с цветной квадратной иконкой слева (лайм, розовый, синий, жёлтый), название капсом мелко, значение крупно.
- **Графики:** тонкая линия цвета раздела (зелёный на Компьютере в старой версии, можно сделать цветом раздела), сетка едва видна, подписи «90 секунд» и «100%».

## Типографика

- Заголовки: тяжёлый гротеск, очень жирный, широкий (ориентир — Arial Black или аналог с лицензией, которая разрешает встраивание). Точный шрифт подобрать на этапе токенов.
- Текст: обычный sans-serif (например Segoe UI на Windows, Inter или аналог с открытой лицензией).
- Цифры показателей — крупные, жирные.

## Иллюстрации

- На VPN — фото в стиле Warhol (два портрета в квадратах, большой портрет по центру). Для новой версии нужны свои картинки в том же стиле или нейтральный плейсхолдер. Не копировать чужие фото без прав.

## Анимации

- Плавное появление разделов, подсветка активного пункта, сканирование для антивируса (полоса), линии графиков.
- Уважать `prefers-reduced-motion`: отключать движение, оставлять смену состояния.

## Что нельзя менять без согласования

- Порядок и названия семи разделов.
- Цвет фона каждого раздела.
- Фирменную строку внизу.
- Чёрные карточки и скруглённые кнопки.

## Что можно улучшать

- Производительность: анимации через transform и opacity, виртуализация длинных списков.
- Доступность: контраст текста на цветном фоне, размеры кликабельных зон, фокус с клавиатуры.
- Адаптивность под окна разного размера (сейчас окно фиксированного размера).
