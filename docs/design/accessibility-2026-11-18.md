## Имена и роли (4.1.2, 1.3.1)

- Пункты правой панели: `aria-label` с названием раздела, иконки скрыты (`aria-hidden`), `aria-current` у активного.
- Кнопки окна: `aria-label` «Свернуть», «Развернуть», «Закрыть».
- Заголовок страницы — `h1`, язык документа `ru`.
- Ошибки: `role="alert"`. Ход проверки: `aria-live="polite"`. Уровень подозрительности: `role="meter"` с значениями.
- Поле «Папка для проверки» связано с подписью (label вокруг input).
- Поле импорта VPN выключено и имеет `aria-label`.

## Движение

- Полоса сканирования в «Вирусах» останавливается при `prefers-reduced-motion: reduce`. Правило есть в CSS, отдельного теста нет.

## Не проверено

- Экранные читалки: порядок чтения и объявления не слушались.
- Масштаб 200%: вёрстка правой панели фиксированной ширины, перенос текста не проверялся.
- Тёмная и светлая темы: приложение только тёмное, отдельной темы нет.

## Вывод

Критичных нарушений нет. Два средних (размер кнопок окна и вкладок, фокус) исправлены. Остаются проверки, которые можно сделать только на Windows с читалкой.
