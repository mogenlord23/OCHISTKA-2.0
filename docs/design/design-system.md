# Дизайн-система: аудит и токены, 2026-11-18

Источник токенов: `apps/desktop/src/lib/tokens.ts`. Они же выставляются на корневой блок приложения как CSS-переменные (`App.svelte`).

## Аудит (до правок)

| Категория         | Было                                                  | Стало                                     |
| ----------------- | ----------------------------------------------------- | ----------------------------------------- |
| Цвета разделов    | 7 значений в `sections.ts`                            | в `SECTION_COLORS`, один источник         |
| Нейтральные цвета | 7 цветов литералами в 7 компонентах                   | в `NEUTRAL`, компоненты читают `var(--…)` |
| Размеры текста    | 7 значений (11, 12, 13, 14, 16, 26, 44 px) литералами | в `TYPE_SCALE`, `var(--text-…)`           |
| Скругления        | 3 значения литералами (8, 12, 14 px)                  | в `RADIUS`, `var(--radius-…)`             |
| Шрифты            | Arial Black и Segoe UI литералами                     | `HEADING_FONT`, `BODY_FONT`               |

Оценка покрытия токенами: после правок все нейтральные цвета, размеры и основные скругления идут через токены. Литералы GitHub-палитры (`#21262d`, `#1f6feb`, `#da3633`, `#8b949e`, `#161b22`) убраны из компонентов Home и VirusesPage; цвет ошибки вынесен в токен `ERROR_COLOR` (`--error`). Остались `#1f1f1f` и `#1a1a1a`.

Компоненты «Таблица», «Переключатель», «Плитка комплектующей» из брифа пока не созданы: их добавим, когда будем строить соответствующие разделы. Их токены готовы: цвет раздела, `RADIUS.md`, `NEUTRAL.surface`.

## Правила

1. Новый цвет — только через `tokens.ts`, литералов в компонентах не пишем.
2. Текст на цветном фоне — `textOn(...)`, не чёрный по умолчанию.
3. Размер текста и скругление берём из шкалы, своих значений не вводим.
4. Компонент с отключённой кнопкой объясняет причину в `title`.
