# ADR 0004: антивирусный движок — libclamav, собранный из исходников

- **Дата:** 2026-11-18
- **Статус:** принято (окончательное решение пользователя, см. раздел «Антивирус» в CLAUDE.md)
- **Заменяет:** ADR 0002 в части интеграции (вызов `clamscan.exe` снят). Эвристика и правило карантина ADR 0002 остаются.
- **Отменяет:** решение D7 (ClamAV не используем) и черновик YARA-X. Закрытые по D7 находки ClamAV в `findings/` остаются записью истории; повторное открытие по новому решению — отдельным шагом аудита.

## Решение

1. **Один продукт.** libclamav собирается из исходников ClamAV (репозиторий GitHub) и встраивается в приложение. Отдельного `clamscan.exe` и отдельной установки нет. Сборка: CMake, MSVC, vcpkg; скрипт в `tools/clamav-build/`; артефакты в репозиторий не коммитятся.
2. **Граница unsafe.** `unsafe` допускается только в одном FFI-модуле (`crates/platform/src/windows/clamav_ffi.rs`). Снаружи — безопасный трейт `VirusScanPort` в `ochistka-core`.
3. **Сигнатуры** не вшиваются в приложение и обновляются отдельно (механизм обновления — отдельный шаг плана, пункт 6).
4. **Свой слой поверх движка:** инвентаризация (тип файла по заголовку, без запуска), эвристика с причинами, ИИ-слой (локальная ONNX-модель; сейчас интерфейс и заглушка), итоговая оценка с объяснением. ИИ только повышает подозрение; удаляет пользователь.
5. **Не используем:** YARA-X, Microsoft Defender.
6. **Лицензия.** ClamAV — GPL-2.0. Последствия фиксируются в `THIRD-PARTY.md`. Лицензия самой OCHISTKA — TBD (решает владелец до публичного релиза).

## Последствия

- Если сборка libclamav не получилась с одной попытки, ошибка записывается в `docs/status/`, а слой VirusScanPort работает с заглушкой движка: раздел показывает причину, приложение не падает.
- Установщик включает libclamav (статически или рядом), а также текст GPL-2.0 и `THIRD-PARTY.md`.
- Проверка на Windows (сборка, загрузка сигнатур, сканирование) — отдельный пункт статуса.
