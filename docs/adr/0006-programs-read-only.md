# ADR 0006: раздел «Программы» только на чтение

- **Дата:** 2026-11-18
- **Статус:** принято

## Решение

1. **Список установленных программ** читается из ключей `Software\Microsoft\Windows\CurrentVersion\Uninstall`: HKLM в 64-битном и 32-битном видах и HKCU. Реестр читает `winreg` только под `cfg(windows)`; на других ОС — заглушка `Unsupported`.
2. **Разбор в ядре, без ОС.** Записи реестра приводятся к сырому виду (`RawProgramRecord`), разбор, сортировка, удаление повторов и проверка путей — в `crates/ochistka-core/src/programs.rs`.
3. **Системные компоненты и обновления** (`SystemComponent = 1`, `ParentKeyName`) и записи без имени не показываем.
4. **Тип программы:** `Win32`, если есть строка удаления или `WindowsInstaller = 1`; `Store` — для записей реестра пакетов Microsoft Store (чтение пока не подключено); иначе «Другое».
5. **Размер папки** считается тем же обходом, что и остальные разделы (`walk`), с общим лимитом записей и отменой. Путь проверяется на границе команды: абсолютный, без `..`. Системные папки здесь разрешены, потому что это только чтение.
6. **Автозагрузка** — только чтение: ключи Run (HKCU и HKLM) и файлы папок «Автозагрузка» (профиль и общая). Изменение и откат появятся вместе с записью настроек (см. CLAUDE.md, правило про прежнее значение).
7. **Удаление программ не подключено.** Кнопка «Удалить» выключена и показывает причину «Удаление программ пока не подключено». Удаление пойдёт через карантин и отдельное подтверждение, когда будет подключено.

## Последствия

- Реестр Store и удаление записаны в `docs/platform-status.md` как `planned`.
- Всё, что касается реестра, проверено компиляцией под `x86_64-pc-windows-msvc` с Linux; запуск на Windows не проводился.
