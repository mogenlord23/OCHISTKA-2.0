# ADR 0005: карантин

- **Дата:** 2026-11-18
- **Статус:** принято (правило из CLAUDE.md: удаление только через карантин)

## Решение

1. **Перенос, не удаление.** Файл переносится в папку карантина приложения (внутри профиля пользователя, не на системном диске без подтверждения).
2. **Манифест.** На каждый файл пишется запись: исходный путь, SHA-256, дата переноса, причина (сигнатура или оценка с объяснением).
3. **Восстановление** возвращает файл на исходный путь; если путь занят, спрашивает пользователя.
4. **Окончательное удаление** — только по отдельному подтверждению пользователя, для каждого действия отдельно.
5. **Системные папки и пути вне белого списка** в карантин не переносятся никогда.
6. ИИ и эвристика не переносят и не удаляют файлы сами.
