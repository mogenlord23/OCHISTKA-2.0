# ADR 0010: решения по правкам после просмотра v2

- **Дата:** 2026-11-18
- **Статус:** принято

## Решения

1. **Шаблон страницы.** Все разделы используют один компонент страницы (заголовок, описание, вкладки, сетка карточек, общие отступы кратные 8 px). Отличия раздела — только содержимое.
2. **Блок языка RU/EN** внизу панели. По умолчанию русский. Сворачивается вниз стрелкой-галочкой, которая поднимается при наведении. Нужен, чтобы панель разделов всегда помещалась без прокрутки.
3. **Подсказки при наведении** не показываем, если они описывают сам элемент (названия цветов, HEX, «выбрано»). Текст «пока не подключено» в интерфейсе не используем: функции подключаются, а недоступные отключаются без пояснения.
4. **Версия** в интерфейсе не показывается.
5. **Обои.** Выбранная картинка сразу ставится на рабочий стол Windows. Повторный клик ничего не отменяет. Отмена — только кнопкой «Вернуть как было». Исходное значение запоминается до первого изменения.
6. **Курсоры и цвета.** Применяются к системе Windows, не к приложению. Отмена — «Вернуть как было». Превью курсоров — в реальном размере 32 px.
7. **Выбор элемента** — только обводка по краю плитки, без галочек.
8. **Фон разделов** — картинка из старой версии, приглушённая, cover с фокусом по центру.
