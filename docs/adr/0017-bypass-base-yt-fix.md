# ADR 0017: основа объединённого пресета — «Universal V13 YT FIX»

- **Дата:** 2026-11-21. **Статус:** решение владельца.
1. Основа слияния — «Universal V13 YT FIX» вместо «Universal V13 Lite». ADR 0014, п. 4 (основа V13 Lite) отменён; остальные правила слияния (основа первой, наименьший риск, перехват WinDivert как в основе, дубли убраны, недостижимые секции убраны) не меняются.
2. Основе нужен Lua-модуль `lua/nz-video.lua` (шаг `nz_first2`, MIT, RixyPow). Остальные добавленные ресурсы — списки адресов.
3. Остаются исключения: Telegram, Steam, Riot / Valorant не входят в пресет и маршруты; Claude — только через VPN.
