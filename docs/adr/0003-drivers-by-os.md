# ADR 0003: драйверы по ОС

- **Дата:** 2026-11-17
- **Статус:** принято; пункт 1 (переключатель ОС) заменён ADR 0011 (2026-11-19), остальное в силе

## Контекст

Раздел «Драйверы» показывает драйверы текущей системы. Набор возможностей у ОС разный: Windows позволяет читать список драйверов и устанавливать обновления через системные механизмы, а на macOS и Linux пока речь идёт только о сведениях.

## Решение

1. ~~Сверху раздела — переключатель ОС.~~ Отменено ADR 0011: приложение под Windows, переключателя нет.
2. **На Windows — реальные данные:** список драйверов из Windows (INF-пакеты и Windows Update). Установка только через системные механизмы Windows.
3. **На macOS и Linux в будущем — только инвентаризация и обновления через системные инструменты.** Никакой прямой записи драйверов.
4. **Функции, недоступные на текущей ОС, показываются выключенными с причиной.**
5. **Права администратора запрашиваются только для конкретного действия** (например, установки одного драйвера), а не для всего приложения.
6. **Команды вызываются по абсолютным путям** к системным утилитам, без поиска по PATH.

## Последствия

- На этапе 1 раздел «Драйверы» остаётся заглушкой «в разработке», переключатель ОС не реализован.
- Статус по ОС ведётся в `docs/platform-status.md`: Windows — `planned` до реализации и проверки на Windows, macOS и Linux — `planned`.
- Установка драйверов на Windows требует отдельного подтверждения пользователя для каждого действия и отката, если системный механизм это поддерживает.
