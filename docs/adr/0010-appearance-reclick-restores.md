# 0010. Оформление: повторный клик возвращает прежнее значение

Дата: 2026-11-19

Дополняет 0009 (в 0009 плитки обоев и курсоров меняли только предпросмотр в приложении).

## Решение

- Три группы плиток (обои, курсоры, цвета) работают одинаково: клик ставит значение в Windows, повторный клик по выбранной плитке возвращает значение, которое было до первого клика из OCHISTKA, и снимает обводку. В группе выбрана не больше одной плитки.
- Выбор хранится в Windows-стороне (`HKCU\Software\OCHISTKA\Backup\...`: AppliedWallpaper, AppliedScheme, AppliedAccent) и читается при запуске; localStorage для него не используется.
- Обои: набор владельца (146 фото) лежит в ресурсах приложения. Ядро копирует оригинал в `%LOCALAPPDATA%\OCHISTKA\Wallpapers` и ставит копию.
- Курсоры: схема из 17 ролей рисуется в Rust из векторных фигур, `.cur` содержит кадры 32/48/64/96/128. Прежняя схема сохраняется в `HKCU\Software\OCHISTKA\Backup\Cursors`.
- Цвета: плитка меняет акцент, AccentPalette и ColorPrevalence; снимок этих значений делается перед первой плиткой.
- Все записи идут через порты (`RegistryPort`, `FilePort`, `WallpaperPort`, `CursorRefreshPort`); системные утилиты запускаются по абсолютному пути.

## Последствия

- Оригиналы обоев увеличивают установщик примерно на 105 МБ.
- Кнопка «Скачать оригиналы» и сплошные цветные обои убраны.
- Реальное поведение на Windows пока не проверено (статус implemented, не verified).
