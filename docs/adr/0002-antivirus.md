# ADR 0002: антивирус

- **Дата:** 2026-11-17
- **Статус:** принято частично; способ интеграции с движком не принят

## Контекст

В OCHISTKA есть собственный раздел «Безопасность» с антивирусом. Встроенный Microsoft Defender мы не используем и не управляем им: ни его настройками, ни его исключениями.

## Решение

1. **Движок — ClamAV (лицензия GPL-2.0).** Поиск по сигнатурам и обновление баз.
2. **Способ интеграции (CLI или библиотека) пока не выбран.** Решение будет зафиксировано отдельным ADR до начала реализации сканера.
3. **ИИ-оценка подозрительных файлов — позже, как подсказка.** ИИ не удаляет файлы сам; решение всегда принимает пользователь.
4. **Удаление только через карантин.** Файл переносится в карантин. Окончательное удаление — только по отдельному подтверждению пользователя.
5. **Системные папки и пути вне белого списка не трогаем никогда.**
6. **Интерфейс:** запуск сканирования с анимацией, список найденного, выбор элементов, кнопка «Удалить» (через карантин).

## Последствия

- GPL-2.0 у ClamAV накладывает условия на распространение бинарников. Их нужно проверить до первого публичного релиза; это отдельная задача.
- До реализации сканера раздел «Безопасность» остаётся заглушкой «в разработке».
- Карантин и белый список путей потребуют отдельных тестов, прежде чем появится кнопка «Удалить».
