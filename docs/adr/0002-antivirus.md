# ADR 0002: антивирус

- **Дата:** 2026-11-18
- **Статус:** принято

## Контекст

Раздел «Вирусы» — первый в навигации. Встроенный Microsoft Defender мы не используем и не управляем им. Старая версия приложения работала на YARA и скриптах Defender; здесь мы от них уходим. Нейросеть должна работать только локально: файлы пользователя не отправляются наружу.

## Решение

1. **Движок — ClamAV (GPL-2.0).**
2. **Способ интеграции — вызов `clamscan.exe` как внешней программы** по абсолютному пути из папки установки. Библиотеку `libclamav` не используем: она тянет больше GPL-кода в наше приложение и сложнее в сопровождении. Программа запускается без PATH-поиска, с ограниченными аргументами; результат читаем из стандартного вывода.
3. **Обновление баз — `freshclam`**, тоже по абсолютному пути.
4. **Нейросеть на этапе 1 — эвристическая оценка.** Правила: двойное расширение, исполняемый файл в загрузках или автозагрузке, подозрительное имя, размер. Оценка только подсказывает. Позже вместо правил подключим ONNX-модель; выбор модели и проверка её лицензии — отдельное решение, которое зафиксируем новым ADR.
5. **Удаление только через карантин.** Файл переносится в карантин, окончательное удаление — только по отдельному подтверждению. На этапе 1 кнопка «Удалить» выключена с причиной «карантин — следующий шаг».
6. **Системные папки и пути вне белого списка не трогаем никогда.**

## Последствия

- Установщик включает `clamscan.exe`, `freshclam.exe` и их лицензии (GPL-2.0). Условия распространения бинарников проверяем до публичного релиза.
- Без установленного ClamAV раздел показывает причину («движок ClamAV не найден») и не падает.
- Без нейросети разделы работают; эвристика — честная подсказка, а не вердикт.
