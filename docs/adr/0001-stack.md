# ADR 0001: стек приложения

- **Дата:** 2026-11-17
- **Статус:** принято

## Контекст

OCHISTKA — утилита обслуживания компьютера. Текущий этап — Windows 10/11 x64. Позже нужны macOS и Linux без переписывания интерфейса и ядра. Приложению нужны десктопное окно, доступ к системным сведениям и операциям, а также небольшой установщик.

## Решение

- **Tauri 2** — оболочка приложения. Интерфейс работает в системном WebView (WebView2 на Windows, есть в Windows 11), установщик получается небольшим, связь с ядром идёт через типизированные команды Tauri.
- **Rust** — ядро и системные операции. Безопасность памяти, один язык для адаптеров по ОС, зрелые библиотеки (например, sysinfo для чтения сведений о системе).
- **Svelte 5 + TypeScript** — интерфейс. Небольшой рантайм, руны для состояния, статическая проверка типов.
- **Vite** — сборка и сервер разработки; Tauri использует его по умолчанию.

Не используем: WPF. Старый код WPF остаётся справкой по поведению и не копируется.

## Последствия

- Сборка на Windows требует MSVC Build Tools с рабочей нагрузкой C++ и WebView2.
- Структура репозитория: `apps/desktop` (Tauri и интерфейс), `crates/ochistka-core` (логика без UI), `crates/platform` (адаптеры по ОС). Подробности — в [ADR 0001-stack-and-platform-layers](0001-stack-and-platform-layers.md).
- Проверки качества: `cargo fmt --check`, `cargo clippy -- -D warnings`, `cargo test`, `svelte-check`, `vitest`, Prettier.
- Типы фронтенда пишутся вручную и должны совпадать с DTO ядра.
