# ADR 0014: «Обход блокировок» — одна кнопка и один объединённый пресет

- **Дата:** 2026-11-21
- **Статус:** принято владельцем, реализация не начата

## Контекст

Проверка на Windows: YouTube и Discord открываются медленно, Telegram не открывается. Текущая кнопка использует один пресет «Universal V13 Lite» и не покрывает Telegram. В репозитории RixyPow/netzapret больше ста пресетов десинка, маршрутов по приложениям и играм и Telegram-прокси.

## Решение

1. **VPN не входит в «Обход блокировок».** Это отдельная функция. Взаимное исключение: включение «Обход блокировок» выключает VPN, включение VPN выключает «Обход блокировок» (NetCoordinator).
2. **Одна кнопка, без выбора пресета.** Пользователь не выбирает пресеты, маршруты и режимы.
3. **Все пресеты десинка из RixyPow/netzapret объединяются в один пресет.** Повторяющиеся правила и аргументы удаляются, чтобы не дублировались. Итоговый пресет — один файл.
4. **Маршруты по приложениям, играм и доменам** из того же репозитория переносятся как данные и применяются тем же переключателем.
5. **Telegram-прокси** (локальный адрес 127.0.0.1:1443) включается вместе с кнопкой. Настройку Telegram Desktop приложение делает само или подсказывает один раз.
6. **Перенос данных.** Пресеты и маршруты берутся как файлы настроек, не как код. В проект кладутся с их лицензиями и указанием авторов в `THIRD-PARTY.md`. Код движков (GPL v3, LGPL, Wintun) не копируем без отдельного решения о лицензии OCHISTKA.
7. **Существующие правила проекта не меняются:** 135 файлов NetZapret, оригинальный «Universal V13 Lite», SHA-256, подпись драйвера, откат, 120-секундный испытательный режим, без автозапуска.

## Последствия

- Объединение может дать конфликты: два пресета могут требовать несовместимых аргументов для одного и того же трафика. Такие случаи записываются в отчёт, а не решаются молча отбрасыванием.
- Объединённый пресет не объявляется рабочим, пока не проверен на Windows у провайдера.
