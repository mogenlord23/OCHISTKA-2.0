# ADR 0023: служба VPN для «Весь компьютер», права администратора один раз при установке

- **Дата:** 2026-11-22. **Статус:** решение владельца. Закрывает открытый вопрос о правах из ADR 0022.

## Решение

1. Режим «Весь компьютер» (туннель TUN) требует прав администратора. Их запрашивает только установщик, один раз: он регистрирует службу `OchistkaVpn` (от имени системы, запуск «вручную», автозапуска нет) и выдаёт обычным пользователям права запускать и останавливать только её.
2. Приложение запускает и останавливает службу через диспетчер служб Windows (без запросов прав и окон). Нет службы → «Переустановите программу, чтобы включить режим «Весь компьютер»». Выключение ждёт состояния «остановлена» до 20 секунд. «Только сайты» не меняется и прав не требует.
3. sing-box сам не умеет быть службой Windows, поэтому служба — небольшая оболочка (`crates/vpn-host`): ядро берётся только из папки программы (`vpn-core\sing-box.exe`; установка «для всех пользователей», папка доступна на запись только администратору); конфигурация приходит аргументом запуска и проверяется (знакомые разделы, входы `mixed` на 127.0.0.1 и `tun`, без записи журнала в файл и внешних наборов правил); файл с ключами стирается через 3 секунды после запуска ядра.
4. Установщик пишет `%ProgramData%\OCHISTKA\install.log` (шаги, права, файлы, команды, ошибки). Если регистрация не удалась, установка продолжается.
5. Проверка установки на Windows — workflow `vpn-service-check` (вручную); результат: `docs/status/vpn-service-check.md`.

## Остаточный риск и открытое

- Любой локальный пользователь может запустить службу со своей конфигурацией в пределах списка допустимого (за пределы — отказ). Список строгий, но это расширение прав, о котором надо помнить.
- Туннель с подпиской владельца на Windows не проверялся; не проверен запрос прав при установке у владельца и запуск службы обычным пользователем.
