# ADR 0019: прежний обход блокировок удалён

- **Дата:** 2026-11-22. **Статус:** решение владельца. Отменяет ADR 0018 (и тем самым ADR 0014 и 0017 в части движка).

## Решение

Прежняя система «Обход блокировок» удалена полностью: движок SonicDPI (`ochistkadpi.exe`), драйвер WinDivert и его служба, остановка процессов по номеру, запуск с повышением прав (UAC), служба и команды кнопки, сама кнопка. Из установщика убраны файлы движка, из сборки на GitHub — скачивание, проверка и записи о нём.

## Что осталось (VPN и общее)

- VPN: ядро, подписки, серверы, маршруты, интерфейс.
- `crates/ochistka-core/src/desync/coordinator.rs`: общее право на сетевой режим; VPN по-прежнему отказывается включаться, пока им владеет другой участник (место для нового обхода).
- `desync/probe.rs` (и `crates/platform/src/desync/probe.rs`) и `desync/routing.rs` (результаты проверки доступности): их использует VPN.
- Панель «Сайты» (интерфейс и хранение списка в `%LOCALAPPDATA%\OCHISTKA\desync\user-sites.json`). Подпись панели: «Сайты, которые открываются через обход».
- В интерфейсе карточка «Обход блокировок» остаётся без кнопки (надпись «Появится позже») и с кнопкой «Сайты».

## Что открыто

- Новый обход будет написан заново (движок, права, статус, проверка работы).
- Файлы `assets/desync/routes/OCHISTKA Routes.json` и прежние отчёты `docs/status/bypass-*`, `dpi-engine-audit.md` не тронуты как справочный архив.
- Тестовая строка со старым адресом выпуска в `crates/ochistka-core/src/vpn/engine.rs` оставлена: это код VPN.
