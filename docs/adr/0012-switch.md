# ADR 0012: единый переключатель Switch, Check только для списков

- **Дата:** 2026-11-19
- **Статус:** принято (круг 4, пункт 1). Дополняет правило круга 3 «все флажки одним компонентом Check».

## Контекст

Один компонент `Check.svelte` с нарисованной галочкой использовался и для «включить / выключить» (настройки, Boost, цвета), и для выбора нескольких строк в списке (категории очистки, найденные файлы). Владельцу галочка не нравится, а переключатели в списках настроек выглядят как выбор строки.

## Решение

1. **`Switch.svelte`** для любого «включить / выключить». Пилюля высотой 24 px в стиле кнопки подключения VPN: выкл — тёмная заливка, белая обводка, ручка слева; вкл — заливка цветом раздела (`--accent`), ручка справа. Анимация 160 мс одинаковая везде. `role="switch"`, `aria-checked`, настоящая кнопка (клавиатура, фокус).
2. **Состояния:** выкл, вкл, ожидание (`pending`: ручка пульсирует), ошибка (`error`: красная обводка), недоступно (`disabled`, с причиной рядом в строке). Компонент не хранит состояние: родитель передаёт `checked`, нажатие лишь сообщает желаемое значение. Оптимистичный показ в тот же кадр и откат при ошибке делает родитель (`TweakRunner`, `optimisticRun`), с короткой фразой.
3. **`Check.svelte`** остаётся только для множественного выбора в списках. Галочки нет: выбран = заливка цветом раздела, не выбран = тёмный квадрат с обводкой.
4. Выбор карточек и плиток — белая обводка (как у обоев). Разовое действие — обычная кнопка.
5. Заменено на Switch: Компьютер → Настройки и Boost, Оформление → Цвета, VPN (готовые наборы маршрутов, «Дополнительно»). Остались на Check: Диски (категории очистки), Вирусы (находки).

## Последствия

Тесты ищут `role="switch"` и читают `aria-checked`. Новый on/off-элемент делают только через Switch.
