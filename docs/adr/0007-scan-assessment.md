# ADR 0007: проверка папки, итоговая оценка и карантин находок

- **Дата:** 2026-11-18
- **Статус:** принято
- **Дополняет:** ADR 0004 (движок и слои поверх него) и ADR 0005 (карантин).

## Решение

1. **Движок видит один файл.** `VirusScanPort::scan_file(path)` проверяет один файл. Обход папки, лимит размера, отмена и сводка — в `ochistka-core` (`scan::sweep`). Так движок можно заменить фейком в тестах без диска и без libclamav.
2. **Лимит 200 МБ.** Файлы больше `MAX_FILE_BYTES` движку не отдаются; они считаются в `skippedFiles` и показываются в журнале.
3. **Ошибка одного файла не останавливает проверку.** Повреждённый или занятый файл считается в `errors`.
4. **Нет движка — проверка не начинается.** Если движок недоступен, `sweep` сразу возвращает причину (`движок не собран`), обход не идёт.
5. **Находки = попадания движка по сигнатуре.** Оценка слоёв (ниже) показывается у каждой находки, но сама по себе находкой файл не делает: подозрительные файлы без сигнатуры в список не попадают.
6. **Итоговая оценка — три слоя, каждая причина помечена слоем:**
   - инвентаризация: тип по первым 512 байтам (без запуска) и расширение; документ с заголовком программы даёт +60;
   - эвристика по имени и месту (двойное расширение, программа в «Загрузках» или автозагрузке, маленький размер, слова взломщиков);
   - ИИ-слой: трейт `SuspicionModel`, сейчас заглушка `NoModel` (ничего не возвращает). Локальная ONNX-модель подключится за тем же трейтом. Мнение модели добавляет половину своей оценки и не может её снизить.
   - Итог ограничен 100.
7. **Карантин находок.** «Удалить» переносит выбранные находки в карантин существующим `Quarantine::move_many` (запрос `quarantineFindings`). Белый список карантина расширен папкой «Загрузки» пользователя; всё остальное по-прежнему отказывается. За один запрос — не больше 500 файлов. Окончательное удаление — только из журнала, отдельным шагом подтверждения и с токеном записи (`purge:<id>`).
8. **FFI за фичей.** `unsafe` — только в `crates/platform/src/windows/clamav_ffi.rs` и только при сборке с фичей `libclamav` (по умолчанию выключена). Объявления функций libclamav не сверены с заголовками (исходники не получены, см. `docs/status/clamav-build.md`).

## Последствия

- Без сборки libclamav движок — заглушка: раздел показывает причину, приложение не падает, оценка и карантин работают на уже найденных файлах.
- Тесты EICAR и отказ с заглушкой идут на настоящей временной папке; файл 200 МБ создаётся разреженным.
- Проверка на Windows (сборка, сигнатуры, карантин в настоящей «Загрузках») — отдельный пункт статуса.
