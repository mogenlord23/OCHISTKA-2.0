# ADR 0025: VPN — только «Весь компьютер», без исключений по зонам

- **Дата:** 2026-11-22
- **Статус:** принято владельцем

## Контекст

Исключения для сайтов зон `.ru` и `.рф` (ADR 0024) не заработали: на Windows сайты не открывались
(сначала DNS, потом сброс соединения, потом ядро не запускалось). Проверить каждый вариант на
вашем компьютере без запуска ядра здесь не удалось.

## Решение

1. VPN работает на весь компьютер, как обычный VPN: одна кнопка включения, без выбора областей.
2. Правила для зон `.ru` и `.рф` и российский DNS убраны из кода. Имена резолвятся через DNS туннеля,
   как для всех сайтов.
3. Функция обхода с драйвером (Zapret, только Windows) — отдельно, во вкладке «Дополнительно», позже.
   На macOS и Linux такой функции не будет.

## Последствия

- Сайты, которые требуют отключить VPN, могут не открыться. Это известное ограничение.
- ADR 0024 отменён.
