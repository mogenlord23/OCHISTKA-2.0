# ADR 0021: старый обход удалён, VPN с тремя режимами маршрутов

- **Дата:** 2026-11-22. **Статус:** решение владельца. Отменяет ADR 0020 (локальный прокси «Обход сайтов») и службу обхода этапа 12; ADR 0014–0020 остаются как история.

## Решения

1. Старый обход удалён полностью: локальный прокси (`crates/proxy-bypass`), оболочка службы (`crates/bypass-host`), адаптеры системного прокси для «Обхода сайтов», управление службой, NSIS-хуки и скрипты службы, скачивание `ochistkadpi` в CI, workflow `windows-service-check`, карточка «Обход сайтов» и заметки о них. VPN (ядро, подписки, серверы, маршруты, его системный прокси), панель «Сайты» и её список, общее право на сетевой режим (`NetCoordinator`) остались.
2. В разделе VPN три режима маршрутов; выбирается один и подсвечивается; режим выбирается до включения; отдельная кнопка «Включить VPN»:
   - «Напрямую» (по умолчанию): через VPN ничего; включить VPN нельзя (кнопка недоступна, ядро отказывает).
   - «Только сайты из списка через VPN»: через VPN идут сайты из панели «Сайты» (и явные «через VPN» пользователя из вкладки «Дополнительно»), всё остальное напрямую (`final = direct`).
   - «Все сайты через VPN»: всё через VPN, кроме локальных адресов и исключений пользователя (`final = proxy`).
   Смена режима при включённом VPN: «Напрямую» отключает VPN, другой режим переподключает. Правка списков маршрутов режим не сбрасывает. Повторное нажатие выбранного режима «через VPN» возвращает «Напрямую».
3. Подписка: как только вставлена корректная ссылка https:// (длина поля выросла сразу на много знаков), она импортируется сама; побуквенный набор не импортирует недописанный адрес. Кнопки «Импорт» нет; «Из файла…» стоит на её месте. Список ссылок серверов (не https) импортируется по Enter или из файла.
4. Список сайтов из панели «Сайты» используется только в режиме «Только сайты из списка через VPN».
5. Серверов в программе нет: каждый пользователь вставляет свою подписку.

## Не проверено

- Реальный VPN с подпиской владельца на Windows в каждом из трёх режимов.
- Поведение приложений, которые не используют системный прокси (VPN работает через системный прокси).
- Переподключение при смене режима на живом соединении (проверено только на тестовых заглушках).
