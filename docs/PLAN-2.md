## A. Заглушки, которые можно закрыть без Windows

- [x] Sysinfo 0.40.4 содержит GPU- и материнскую плату на Windows (`Gpus`, `Motherboard`). Подключить как порт, вывести в плитку «GPU» и «Материнская плата», на Linux — «Unsupported» с причиной.
- [x] Программы: чтение Microsoft Store (реестр пакетов), тип «Store».
- [x] Службы: список служб через безопасный крейт (без своего unsafe), на Linux — заглушка.
- [x] VPN: декодирование base64-подписок и поле `ps` для vmess.
- [x] VPN: подтверждение перед включением Zapret и Xbox DNS (диалог, без изменения сети).
- [x] Диски: «восстановление в другой путь», если исходный занят (ADR 0005 п. 3); флаг неполного обхода в скане (лимит 300 000).
- [x] Перевод: все строки оболочки и подписи разделов на английский через JSON.

## B. Кроссплатформенность (архитектура без реализации)

- [x] `docs/platform-status.md`: каждая функция × ОС, статусы `implemented` / `planned`, никаких `verified` без проверки.
