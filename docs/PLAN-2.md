## A. Заглушки, которые можно закрыть без Windows
- [ ] Sysinfo 0.40.4 содержит GPU- и материнскую плату на Windows (`Gpus`, `Motherboard`). Подключить как порт, вывести в плитку «GPU» и «Материнская плата», на Linux — «Unsupported» с причиной.
- [ ] Программы: чтение Microsoft Store (реестр пакетов), тип «Store».
- [ ] Службы: список служб через безопасный крейт (без своего unsafe), на Linux — заглушка.
- [ ] VPN: декодирование base64-подписок и поле `ps` для vmess.
- [ ] VPN: подтверждение перед включением Zapret и Xbox DNS (диалог, без изменения сети).
- [ ] Диски: «восстановление в другой путь», если исходный занят (ADR 0005 п. 3); флаг неполного обхода в скане (лимит 300 000).
- [ ] Перевод: все строки оболочки и подписи разделов на английский через JSON.
