# Статус функций по ОС

Статусы:

- `implemented` — код написан и покрыт тестами, но не проверен на этой ОС;
- `verified` — проверено на реальной ОС (запуск записан в `docs/status/итог.md`). Пока ни одна строка не `verified`: на Windows ещё ничего не запускалось;
- `planned` — запланировано, кода нет или он не подключён; в интерфейсе выключено с причиной;
- `unsupported` — в этой версии для этой ОС функция не реализуется: адаптер возвращает `Unsupported`, в интерфейсе выключено с причиной.

Причины на macOS и Linux в коде стоят в тексте ошибки `Unsupported` («Недоступно на macOS в этой версии» / «Недоступно на Linux в этой версии»). Для варианта ошибки с полями `feature` и `os` интерфейс показывает «<функция> недоступно на <ОС>».

## Примечания

- Код Windows собирается под `x86_64-pc-windows-msvc` (`cargo check -p ochistka-platform -p ochistka-core --target x86_64-pc-windows-msvc`, 2026-11-18). Это проверка компиляции, не запуск.
- macOS: стандартная библиотека `aarch64`/`x86_64-apple-darwin` в этой среде не установлена, поэтому компиляция под macOS не проверена. Стабы компилируются и тестируются на Linux.
- Ни одна строка не `verified`: в `docs/status/итог.md` записано, что на Windows ничего не запускалось.
- Вирусы: libclamav не собран (см. `docs/status/clamav-build.md`). Проверка по сигнатурам идёт через `VirusScanPort`; на Windows и на Linux юнит-тесты прогонялись только фейковым движком.
- Процессы на Windows: sysinfo, проценты CPU делятся на число ядер. Завершение и путь к exe не проверены на реальной Windows, поэтому статус `implemented`.

- Списки Процессы, Службы, Автозагрузка (и Установленные) занимают всю высоту до низа страницы, прокрутка внутри, строки фиксированной высоты. Проверено в браузере с макетом данных на 1179x803 и минимальном 900x712 (статус `verified` только для вида, не для Windows).
- Оболочка (круг 5, T2): запрет стандартного меню WebView везде, кроме полей ввода и `.selectable`; выделение текста выключено в интерфейсе и включено в полях и `.selectable`, розовое `::selection` (контраст 5,5:1); плавная смена фона раздела 360 мс (только `background-color` сцены); док «Звук/RU/ENG» одного размера без обводки; «Оформление → Цвета» тремя карточками в одну линию; меню Программ и Процессов у точки нажатия (прокручиваемая область с `contain` делает её началом координат для `position: fixed`, учтено); выравнивание VPN по нижней линии постера (900x712, 1400x900, 1920x1080). Статус `implemented`, виды проверены в браузере (Chromium), в окне Tauri на Windows не проверялись.
- Навигация (2026-11-20): компактная панель вкладок с ползунком, ползунок на правой панели, переключение зажатой мышью (общий модуль `lib/dragSelect.ts`), слово OCHISTKA по оси кнопок окна, строки «Create: Slava Lavs» и крупного заголовка над вкладками нет. Статус `implemented`: проверено в тестах (vitest, jsdom) и по геометрии в Chromium на 900x712, 1179x803, 1920x1080 для всех семи разделов (`docs/status/nav-redesign/geometry.mjs`); в окне Tauri на Windows не проверялось (WebView2, DPI, нативное перетаскивание окна по области шапки).
