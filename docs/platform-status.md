# Статус функций по ОС

Статусы:

- `implemented` — код написан и покрыт тестами, но не проверен на этой ОС;
- `verified` — проверено на реальной ОС (запуск записан в `docs/status/итог.md`). Пока ни одна строка не `verified`: на Windows ещё ничего не запускалось;
- `planned` — запланировано, кода нет или он не подключён; в интерфейсе выключено с причиной;
- `unsupported` — в этой версии для этой ОС функция не реализуется: адаптер возвращает `Unsupported`, в интерфейсе выключено с причиной.

Причины на macOS и Linux в коде стоят в тексте ошибки `Unsupported` («Недоступно на macOS в этой версии» / «Недоступно на Linux в этой версии»). Для варианта ошибки с полями `feature` и `os` интерфейс показывает «<функция> недоступно на <ОС>».

## Примечания

- Код Windows собирается под `x86_64-pc-windows-msvc` (`cargo check -p ochistka-platform -p ochistka-core --target x86_64-pc-windows-msvc`, 2026-11-18). Это проверка компиляции, не запуск.
- macOS: стандартная библиотека `aarch64`/`x86_64-apple-darwin` в этой среде не установлена, поэтому компиляция под macOS не проверена. Стабы компилируются и тестируются на Linux.
- Ни одна строка не `verified`: в `docs/status/итог.md` записано, что на Windows ничего не запускалось.
- Вирусы: libclamav не собран (см. `docs/status/clamav-build.md`). Проверка по сигнатурам идёт через `VirusScanPort`; на Windows и на Linux юнит-тесты прогонялись только фейковым движком.
- Процессы на Windows: sysinfo, проценты CPU делятся на число ядер. Завершение и путь к exe не проверены на реальной Windows, поэтому статус `implemented`.
