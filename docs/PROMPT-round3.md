## Общие правила (для каждого помощника)
1. Не менять то, о чём не просили. Скругления, тени, отступы, шрифты — как в f15de11, пока владелец не скажет иное.
2. Одно скругление во всём приложении: окно, карточки, плитки, кнопки, поля — берутся ТОЛЬКО из токенов (`--radius-*` в tokens.ts/CSS). Своих чисел в компонентах нет. VPN не исключение.
3. Никаких окон-предупреждений и подтверждений в обычных действиях (настройки, Boost, цвета, обои, курсоры, драйверы). Нажал — сразу выполнилось, плавная анимация нажатия. Подтверждение только для безвозвратного удаления файлов (правило карантина).
4. Выбор мгновенный: обводка выбранного появляется в тот же кадр (оптимистичный интерфейс), система применяется в фоне, при ошибке обводка откатывается и показывается короткая понятная фраза без технических слов.
5. Все выбираемые плитки выглядят одинаково (обводка белая, как у обоев/курсоров), повторное нажатие снимает выбор. Все флажки/переключатели — один компонент `Check.svelte`, одинакового размера, выровнены по тексту и по левому краю, без лишнего пробела слева.
6. Пользователю не показывать технику («ядро не установлено», коды ошибок, «реестр»). Ошибка — по-человечески, с действием.
7. Всё выровнено по линиям в каждом разделе (сетка 8 px, отступы страницы 22 px как в f15de11, подпись «OCHISTKA» на старом месте).
8. Экономия лимита: тесты точечно и тихо, скриншоты по делу (смотреть сами), без аудитов и тяжёлых скиллов. Windows-код здесь не запустить: честно писать «implemented, not verified».

- Док (звук / RU / ENG): раскрытый док должен иметь сплошной фон окна и перекрывать плитки (скрывать цвет выбранной плитки «Оформление» под собой), без просвечивания.

## Блок B: Оформление
- Курсоры:
  - Убрать анимацию-вертушку на плитках (при наведении). На плитках только обычное превью курсора и обводка выбранного.
  - Анимированные курсоры (ожидание, фоновая работа) остаются только в самой Windows при выборе схемы.
  - Ошибка «Не удалось работать с реестром. Операция успешно завершена» — баг: код ошибки 0 (успех) трактуется как ошибка. Найти место (SystemParametersInfoW / winreg возвращает Err с кодом 0), считать код 0 успехом, а настоящий успех проверять чтением значений обратно. После применения реально читать HKCU\Control Panel\Cursors и сверять. Сообщение об ошибке — человеческое.
  - Выбор плитки мгновенный, курсор Windows меняется, повторное нажатие возвращает прежний.
- Обои:
  - Первая группа — ровно 7 плиток: 4 кислотных (розовый, лайм, жёлтый, голубой/фиолетовый), чёрный, белый, красный. Каждая — с тем же узором фона, что в приложении (pop-pattern, как фон приложения, на цвет страницы). Убрать остальные одноцветные плитки (было слишком много).
  - Обои разрешением экрана (PNG из Rust: цвет + узор). Дальше 146 фото.
  - Нажатие — мгновенная обводка, обои ставятся; повторное нажатие и кнопка «Вернуть прежний фон» возвращают прежние обои.
- Цвета:
  - «Вернуть оформление Windows» — обычная кнопка без квадратика: нажал — всё вернулось как было.
  - «Залить панель задач» и «Эффект прозрачности» взаимоисключающие: включение одного выключает другое (радио-поведение, но с возможностью выключить оба).
  - Убрать лаги: одно применение — одна запись и одна рассылка, не блокировать интерфейс, не дёргать рабочий стол; применять в фоне через очередь; обводка мгновенно.
  - Квадраты выровнены (нет пробела слева), через Check.svelte.

## Блок C: VPN, драйверы, процессы, программы
- VPN:
  - Убрать надпись про «ядро не установлено» и команду. Пользователь ничего не скачивает руками: ядро (sing-box, закреплённая версия, проверка SHA-256 из tools/vpn-core) скачивается приложением само при первом «Подключиться» в %LOCALAPPDATA%\OCHISTKA\vpn-core с прогрессом на кнопке («Подготовка VPN…»); сборка тоже может класть ядро в ресурсы. Если скачать не удалось — фраза «Не удалось подготовить VPN: проверьте интернет» и «Повторить».
  - Скругления всех карточек VPN — из общих токенов, как в остальных разделах (сейчас отличаются).
  - «Маршруты и исключения»: флажки через Check.svelte.
- Драйверы:
  - Убрать кнопку «Все». Плитки производителей — одинаковые квадраты одного размера (NVIDIA, AMD, Intel, Realtek, Wi-Fi/Bluetooth, USB, Производители ПК), ровная сетка.
  - Нажатая плитка обводится белым, как в обоях; повторное нажатие снимает выбор, и тогда показаны все драйверы.
  - Проверить КАЖДУЮ ссылку каталога (HEAD/GET из песочницы, если сеть доступна): исправить те, что ведут не туда или в ошибку, на правильные официальные страницы/установщики; для ненайденных — страница поддержки производителя. Вести таблицу «карточка → ссылка → код ответа» в docs/status/drivers-links.md.
- Процессы: при открытии сразу сортировка по загрузке CPU от большего к меньшему. Дальше пользователь сортирует сам.
- Программы: при открытии сразу сортировка по размеру от большего к меньшему.
