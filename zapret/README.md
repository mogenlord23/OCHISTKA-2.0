# Zapret для ОЧИСТКИ

ОЧИСТКА 0.5.5 использовала [Flowseal 1.10.4](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.4), сборку Zapret для Windows. Архив `zapret-discord-youtube-1.10.4.zip` сверили по SHA-256:

```text
291af673bd0238506f9548e0e94ca0abf244000f4c9a06960544fb01c5f97b34
```

Четыре файла показали те же SHA-256, что и в установленной ОЧИСТКЕ 0.5.5.

| Файл | SHA-256 |
| --- | --- |
| `bin/winws.exe` | `affb4f69d2ea302a7abccd5325d81826e140ddae014f1e070bc4a6c0dd555188` |
| `bin/WinDivert64.sys` | `8da085332782708d8767bcace5327a6ec7283c17cfb85e40b03cd2323a90ddc2` |
| `bin/WinDivert.dll` | `c1e060ee19444a259b2162f8af0f3fe8c4428a1c6f694dce20de194ac8d7d9a2` |
| `bin/cygwin1.dll` | `103104a52e5293ce418944725df19e2bf81ad9269b9a120d71d39028e821499b` |

Это справка о старом комплекте. Для поставки движка нужно отдельно закрепить источники и условия распространения каждого компонента: [Zapret](https://github.com/bol-van/zapret), [WinDivert](https://github.com/basil00/WinDivert), [Cygwin](https://cygwin.com/licensing.html), списки и дополнительные ресурсы выбранного профиля.

Список, импортированный из «VPN → Дополнительно → Запрет», хранится локально в подпапке `zapret` каталога данных обхода. Импорт добавляет адреса к списку и удаляет повторы. Этот список отделён от маршрутов VPN.

Обычное включение требует проверенного запуска и остановки на Windows. Подготовка WinDivert — явный шаг с правами администратора. После неё управление должно идти через один сервис приложения без консольного окна. Перед запуском одного режима нужно подтвердить успешную остановку другого через общий `NetCoordinator`. На macOS и Linux карточка скрыта.
