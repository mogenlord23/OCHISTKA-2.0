## Локальный запуск на Windows

В «VPN → Дополнительно → Запрет» выберите распакованную папку [Flowseal 1.9.0b](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.9.0b). В ней должны быть `general.bat`, `bin` и `lists`. Модифицированные списки из этой папки сохраняются и используются на месте. Дополнительные домены, импортированные в ОЧИСТКУ, участвуют в запуске через отдельную объединённую копию общего списка.

Этот адаптер рассчитан на Windows-сборку ОЧИСТКИ, запущенную от имени администратора. После выбора папки переключатель запускает `winws.exe` без консоли. ОЧИСТКА проверяет хэши оригинального `general.bat`, бинарников и файлов пакетов, передаёт параметры напрямую, сначала проверяет их с `--dry-run` и не вызывает `service.bat`. Архив 1.9.0b сверили по SHA-256 `1f4e468621d41192d46413f03a7b63063874492e1f59784716be332d1e30031b`.

ОЧИСТКА завершает только свой процесс Zapret. VPN и Zapret делят право запуска через `NetCoordinator`. Если предыдущий режим не завершился, второй не запускается. На macOS и Linux карточка скрыта.
