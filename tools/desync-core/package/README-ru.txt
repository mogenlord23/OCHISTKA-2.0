OCHISTKA: проверка обхода блокировки одного сайта (Windows 10/11 x64)
=====================================================================

Это добровольная диагностика. Она НЕ включает «Обход блокировок» в OCHISTKA и ничего не устанавливает.

Как запустить
1. Выключите VPN и другие прокси-программы.
2. Нажмите на OCHISTKA-DPI-Check.exe ПРАВОЙ кнопкой мыши и выберите «Запуск от имени администратора».
   (Программа сама права не запрашивает.)
3. Введите адрес сайта, который у вас не открывается (например, example.org), и ответьте словом ДА на два вопроса.
4. Дождитесь итога. Отчёт сохранится рядом с программой в файле OCHISTKA-DPI-report-....txt.
   В нём нет паролей, ссылок и содержимого страниц: только имя сайта, названия исходов и время.

Что делает проверка
- Один раз открывает сайт без обхода. Если сайт открылся, движок не запускается.
- Если не открылся, на несколько секунд включает проверенный движок Zapret 2 (папка bundle), который затрагивает
  ТОЛЬКО одно тестовое соединение к этому сайту, затем выключает его и открывает сайт ещё раз.
- Перед запуском проверяются контрольные суммы всех файлов движка и скриптов и действительность подписи драйвера.
  Если хоть один файл изменён, проверка не начинается.
- Настройки Windows, DNS, прокси и защита не меняются.

Защита Windows
Файлы движка (winws2.exe, драйвер WinDivert) известны защитным программам как инструменты работы с пакетами,
поэтому Microsoft Defender может их заблокировать. Защиту не отключайте и исключения не добавляйте: если файл
заблокирован, проверка просто не запустится, это нормально. Сообщить о ложном срабатывании можно в Microsoft
(портал отправки файлов Security Intelligence).

Результат
Итог «улучшение замечено» не доказывает, что блокировка обойдена, и не делает режим готовым для приложения.
Перешлите разработчику только файл отчёта.

Проверить пакет без сети и без драйвера (по желанию):  OCHISTKA-DPI-Check.exe --self-check
Исходный код и лицензии: репозиторий OCHISTKA-2.0, файлы LICENSE-*.txt лежат в папке bundle.
